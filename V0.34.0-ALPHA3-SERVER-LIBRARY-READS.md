# Radio Vault v0.34.0 Alpha 3 — Server-owned Library reads

Alpha 3 is the first native application-service cutover. The dedicated server remains the archive authority, while the native Library, Search library results and Broadcast Info screens now request their complete read models through authenticated loopback HTTP or HTTPS.

## Acceptance

1. Start the matching Alpha 3 `RadioVault.Server.exe` and leave it running.
2. Start the matching Alpha 3 native client.
3. Confirm Dashboard and Library populate normally, including show sections, years, months and listening progress.
4. Exercise Library filters, Search facets and autocomplete.
5. Open Broadcast Info and confirm summary, people, topics, catalogue fields, notes and media structure match the archive.
6. Confirm native and Anywhere playback handoff still works in both directions.

The server and client packages are a matched pair. An older server does not expose the Alpha 3 full-client read routes.

## Deliberate transition boundary

Playback decoding, Library writes, queue, Moments, Research, transcription and settings still use their existing transitional services. They move in later Phase 3 slices after this read boundary is accepted.
