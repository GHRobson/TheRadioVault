# Radio Vault 0.34.0 RC1 Buildfix 2 — new brand identity

This release adopts the approved refined Radio Vault logo throughout the product. The yellow tile preserves the established accent colour while the dark circular broadcast mark also reads as a protected archive or vault.

## Included surfaces

- Radio Vault Client executable, taskbar, shortcut and installer
- Client launch and cache-preparation window
- Native client navigation shell
- Radio Vault Server executable, tray, shortcut, installer and settings screen
- Radio Vault Web boot screen, header, browser/PWA icon, Apple touch icon and maskable icon

All production assets are generated from `design/logo/RadioVault-logo-refined.png` by `design/logo/generate-brand-assets.py`. This keeps small and large sizes visually consistent and avoids separate hand-edited copies drifting apart.

## Upgrade behaviour

The build is an in-place visual update. It does not change the database, server settings, pairings, library folders, transcripts, research packs, certificates, cached data or playback ownership.
