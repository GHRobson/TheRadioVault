# Radio Vault 0.34.0 RC1 Buildfix 4 — client UI and Downloads

This release gives the desktop client and Radio Vault Web a more consistent Radio Vault identity while improving launch, navigation and large-library usability.

The Windows launch screen is now a compact preview of the native shell. It uses the approved client mark prominently and reports the real startup work: choosing the server, opening an encrypted saved workspace when available, checking newer server changes and opening the main window. Cached content remains available between launches and only missing or changed data is refreshed.

Radio Vault Web now keeps the desktop-style navigation rail on wide screens and uses an accessible hamburger drawer on narrower screens. Its Library uses denser native-style rows, smaller primary actions and an overflow menu so controls no longer overwhelm broadcast information.

The Windows client now has its own Downloads destination. Downloads are persistent, isolated by server identity and can be started from Library rows, cancelled, checked, repaired or removed. Playback prefers a verified local copy and continues to preserve progress when the server is temporarily unavailable.

The native player now uses a monitor-and-arrow handoff symbol for moving playback to the PC. The iPhone home-screen icon is generated as an opaque full-bleed yellow tile, and versioned icon URLs prevent an old black-backed icon remaining in Safari's cache.

No archive audio, database, pairing credentials, transcripts, Research packs or transcription models are moved or replaced by this upgrade.
