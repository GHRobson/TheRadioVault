# Radio Vault 0.32.0 RC1 acceptance

RC1 is the Avalonia-only release candidate. The retired WPF application and its WPF/Windows adapter project are no longer part of the solution, launcher, release gate or packaged source.

## Automated gate

Run `RUN-RELEASE-GATE.cmd`. It must complete all of the following:

- Avalonia-only source and architecture validation;
- deterministic Release build of the full solution;
- all 190 smoke tests, including date-review persistence and Research Pack round trips;
- compiled product-version verification against `VERSION.txt`.

## Manual acceptance

1. Build and launch with `BUILD-AND-RUN.cmd`.
2. Confirm the Library and Dashboard load the existing database.
3. Play, pause, seek and resume a normal broadcast and a short recording.
4. Complete Approve, Keep existing, Ignore and Reopen date-review actions.
5. Export and re-import a Research Pack containing resolved date decisions.
6. Enable Radio Vault Anywhere and verify the browser companion can browse and play the archive.
7. Confirm native desktop pairing, federation and handoff controls remain absent; they are post-1.0 work.
