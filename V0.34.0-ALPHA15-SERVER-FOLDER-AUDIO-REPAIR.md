# Radio Vault 0.34 Alpha 15 — server folder assignment and native audio repair

Alpha 15 fixes two regressions exposed by moving archive ownership into the dedicated server.

## Library folders

- Adding a folder in Server settings now always asks which show it contains.
- Folder-name matching preselects known shows such as Unmasked, Ron Bennington Interviews and The Ron & Ron Show.
- Auto-detect / mixed-show remains available for folders that genuinely contain several programmes.
- Existing folders can be selected and corrected with **Change selected show**. Saving the assignment immediately rescans the server Library.
- Opening Library in a paired native client refreshes its show navigation from the server, so newly imported shows do not require a client restart.

## Native audio

- Native playback now uses modern Windows shared-mode WASAPI instead of the legacy WaveOut output path.
- At normal 1x playback the decoded source feeds the output directly, without passing through the speed adapter.
- Radio Vault Web and the native client continue to receive the original server file bytes; the server does not transcode or lower the bitrate.

## Acceptance check

1. Install the Alpha 15 Server on the archive computer and the Alpha 15 Client on the listening computer.
2. In Server settings, add a folder and confirm that the show question appears before it is registered.
3. For an existing mixed folder, select it, choose **Change selected show**, select its programme and save.
4. Wait for the automatic scan to complete, then open Library in the client. Confirm the show appears in the sidebar and its broadcasts are present.
5. Play the same broadcast at 1x in the native client and Radio Vault Web at comparable volume and confirm that the native output is no longer muffled compared with the browser.
