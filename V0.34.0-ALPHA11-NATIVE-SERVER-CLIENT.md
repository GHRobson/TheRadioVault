# Radio Vault v0.34.0 Alpha 11 — Native Server Client

Alpha 11 makes the dedicated server the native application's real data and playback boundary. A paired native client can select the remote server in Settings and, after restarting, uses that server for Library, Dashboard, Search, Queue, Moments, Research, Transcripts, transcription jobs, Broadcast Info, deep research packs and archive administration views.

## Acceptance check

1. Start the Alpha 11 server package on the archive computer and leave it running in the tray.
2. In the native client, open Settings > Server connection, find the server and pair with its six-digit code if it is not already saved.
3. Select **Use paired server**, close Radio Vault completely, and open it again.
4. Confirm the title/status identifies the paired server and that Dashboard, Library and Search show the server archive.
5. Play a broadcast, seek well into it, pause and resume. Confirm audio begins, the playhead is correct and multipart broadcasts cross their part boundary.
6. Move playback between the native client and Radio Vault Anywhere in both directions. Confirm the prior output stops and the new output resumes at the same position.
7. Confirm Queue, Moments, Transcripts, Research and deep research pack operations are visible and update the same server-owned state in Anywhere.
8. In Settings, confirm Archive Health and Library scan reflect the server. Folder mutation remains intentionally server-settings-only.
9. Select **Use this computer**, restart, and confirm the same native app reconnects to the server running locally.
10. After opening several views, temporarily stop the server. Confirm those views remain readable from the encrypted cache, edits/playback fail safely, and starting the server again restores live reads without changing modes.

Database schema remains 45. The API remains v1. Capability generation is 19.
