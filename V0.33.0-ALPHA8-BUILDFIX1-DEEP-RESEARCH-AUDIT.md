# Radio Vault 0.33.0 Alpha 8 Buildfix 1

## Scope

This is a deliberately narrow bugfix release. It verifies the existing Deep Research Pack workflow and audits the active Avalonia application without starting the planned Alpha 9 research features.

## Deep Research Pack acceptance

- Research has one clear **Create Deep Research Pack…** action and one import action.
- A newly created `.trvpack` always contains `manifest.json`, `broadcasts.json`, `missing_broadcasts.json`, `transcripts.json` and `RESEARCH_INSTRUCTIONS.md`.
- The manifest transcript count matches `transcripts.json`.
- Transcript full text, timed segments, speaker labels and speaker keys survive a pack round trip.
- Export and import confirmations display the transcript count.

## Audit fixes

- Applying a Research import performs a real workspace refresh instead of being rejected by the workspace's own busy guard.
- Background theme application is posted safely to Avalonia's UI dispatcher and does not synchronously wait on it.
- Deep Research Pack instructions have a clear title and continuous numbered steps.
- Release validation treats compiler warnings as release failures.

## Regression boundary

All Alpha 8 batch transcription, Alpha 7 transcript review, local playback, Library, Search, Research, Radio Vault Anywhere and archive-maintenance tests must continue to pass.
