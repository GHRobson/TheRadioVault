# Release Notes — Radio Vault v0.31.0 Alpha 1

Build identity: `0.31.0-alpha1-architecture-baseline`

Alpha 1 begins the Core Hardening milestone. It preserves the accepted v0.30.0 feature set while introducing an explicit platform-neutral Application project, a deliberate Windows adapter project, executable architectural dependency rules, a generated coupling report and a migration ledger for the remaining WPF/database/application-service separation.

No library migration, database schema change, LAN capability change, pairing reset, remote cache reset or UI redesign is included.
