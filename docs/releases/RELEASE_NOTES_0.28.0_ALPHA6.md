# Radio Vault v0.28.0-alpha6 — Adoption Preview

Alpha6 converts the confirmed Library Truth shadow model into a migration-design dataset without enabling migration.

Every recording now exports explicit segment coverage. Same-date Standard captures that appear to duplicate one named slot or combine two named slots receive review-only cross-broadcast coverage rows with duration-derived offsets.

Every canonical broadcast also receives a persisted adoption preview. It shows the provisional live episode survivor, files that would move, recording and coverage rows that would be written, and redundant live episode rows that would eventually consolidate. Ready broadcasts are prepared; review and blocked broadcasts stay held.

Nothing in alpha6 can alter the live library.
