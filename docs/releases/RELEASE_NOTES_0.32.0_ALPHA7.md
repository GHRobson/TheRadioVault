# Radio Vault v0.32.0 Alpha 7

Alpha 7 restores important WPF presentation parity in the Avalonia default desktop and adds the first guarded desktop-tools workspace.

## Highlights

- Library List and Grid view modes.
- Cleaner per-show Library presentation.
- Focused compact broadcast information with people and topics.
- Full technical Broadcast information page from the context menu.
- Dedicated full Now Playing page with transport and archive context.
- Simplified left navigation.
- Local Library-folder management, archive health and diagnostics.
- Local and Connected Access broadcast-details boundaries.

## Compatibility

There is no database migration. Schema 45, LAN generation 14, API v1 and all pairing, certificate and encrypted-cache identities remain unchanged.

Advanced destructive or long-running maintenance remains in the retained WPF reference pending parity hardening.
