# Radio Vault v0.32.0 Alpha 8

Alpha 8 is a whole-Avalonia UX audit. It preserves the accepted feature set while making the interface calmer, more contextual and easier to learn.

## Highlights

- Simplified shell navigation and connection status.
- Less crowded persistent playback controls.
- Contextual secondary actions across Dashboard, Library, Now Playing, Queue and Moments.
- Search-as-you-type in Library, Moments and Research.
- Reduced duplicate metrics and technical labels.
- Technical broadcast identity collapsed by default.
- Advanced Research filters and metadata revealed only when requested.
- Simplified Connected Access and Settings & Tools journeys.
- Improved keyboard focus visibility.

## Compatibility

There is no database migration. Schema 45, LAN generation 14, API v1 and all pairing, certificate and encrypted-cache identities remain unchanged.
