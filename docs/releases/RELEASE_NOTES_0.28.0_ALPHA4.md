# Radio Vault v0.28.0-alpha4 — Recording Integrity

Alpha4 is the corrective follow-up to the first complete Library Truth desktop analysis. The broad canonical broadcast model remains intact, while recording assembly is now conservative about filename lineage and numeric ambiguity.

## Highlights

- V1/V2 segment families can no longer be cross-paired.
- Long-form and short-form archive naming families remain separate unless audio evidence later proves equivalence.
- Bare numbers require a sibling sequence before becoming multipart segments.
- Repeated duration clusters and FNR/Eddie Trunk evidence now trigger a suspicious merge.
- Combined AM/PM packages and same-date slot equivalents are surfaced as coverage relationships requiring review.

This release does not adopt the shadow model into the live library.
