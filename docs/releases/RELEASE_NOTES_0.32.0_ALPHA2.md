# Radio Vault 0.32.0-alpha2-avalonia-design-foundation

Alpha 2 turns the successfully launching Avalonia application into the first recognisable Radio Vault desktop shell.

## Highlights

- System-aware dark and light themes.
- New Radio Vault visual tokens and reusable styles.
- Polished sidebar, page header and selected navigation.
- Redesigned Dashboard using real archive data.
- Redesigned canonical Library with clearer rows and details.
- Loading, empty, favourite and attention states.
- Persistent playback-bar foundation for Alpha 3.
- Restyled visible startup experience.

## Compatibility

The Avalonia surface remains local and read-only. The WPF reference retains all existing functionality not yet migrated. Database schema 45, LAN capability generation 14, API v1, pairing, certificates and cache identities are unchanged.
