# Radio Vault v0.28.0-alpha14 — Library Truth Completion

Alpha 14 makes the final compatibility boundary visible and auditable. Canonical playback now rejects structurally incomplete plans, adopted recordings explain why they were selected, and held groups are reported as deliberate fallbacks rather than hidden legacy behaviour.

This release does not automatically resolve the remaining held groups and does not alter audio files. It is intended to be the final architectural alpha before v0.28 beta stabilization, assuming Windows build and acceptance testing pass.
