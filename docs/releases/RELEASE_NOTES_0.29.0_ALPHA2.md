# Radio Vault v0.29.0 Alpha 2 — Anywhere Web App Cutover

Version: `0.29.0-alpha2-anywhere-web-app-cutover`

Alpha 2 moves the secure web companion onto the v0.29 Anywhere foundation. Connected startup uses one bounded bootstrap snapshot, Library navigation gains authoritative date and listening-status facets, and web workflows consistently use canonical broadcast identities.

The active workspace and filters survive a temporary server loss, device-local downloads are clearly separated from the complete server library, automatic reconnection refreshes the current view, and a privacy-safe diagnostics panel records useful browser failures without exposing tokens or archive metadata.

Database schema remains 45. Existing offline audio and artwork caches are retained; only the secure application shell advances to v27.
