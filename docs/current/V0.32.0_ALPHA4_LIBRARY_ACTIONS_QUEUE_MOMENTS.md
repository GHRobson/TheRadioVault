# Radio Vault v0.32.0 Alpha 4 Buildfix 2 — Library Row Polish & Responsive Overscroll

Build identity: `0.32.0-alpha4-buildfix2-library-row-polish-responsive-overscroll`

This build retains the user-accepted Alpha 4 favourites, Queue and Moments workflows and focuses on two interaction corrections discovered during live use.

## Responsive elastic overscroll

Buildfix 1 removed the jitter, but small trailing trackpad deltas could keep resetting its release timer and leave the content visibly suspended at the edge. Buildfix 2 ignores that inertial tail, starts returning after the next meaningful-input frame, and uses a faster single damped spring.

This preserves the no-jitter state while restoring the more immediate feel of Alpha 3. Reduced-motion detection, nearest-scroll-owner protection, ordinary wheel/keyboard scrolling, inertia and scroll chaining remain intact.

## Expandable Library navigation

The Library entry in the Avalonia sidebar is now expandable and collapsible. Its child entries are generated from the actual collections reported by `ILibraryBrowseService`, with one row per show and a broadcast count. Selecting a show opens the existing Library page with `LibraryBrowseRequest.CollectionId` set, so search and listening filters operate inside that show rather than across the complete archive.

The parent Library entry continues to show all broadcasts. The active show is shown in the page title and in a collection pill above the Library list.

## Preserved Alpha 4 workflows

- Favourite toggle from Dashboard, Library and Now Playing.
- Persistent queue: add, play next, reorder, remove, clear, restore and automatic continuation.
- Moments: create at current playback position, search, edit title/notes, delete and jump back into playback.
- Navigation and keyboard shortcuts for Queue and Moments.

Avalonia remains `TheRadioVault.exe`; WPF remains `TheRadioVault.WpfReference.exe`. Schema 45, LAN capability generation 14, API v1, pairing, certificate and cache identities are unchanged.

## Library row refinements

- Per-show Library views omit the redundant collection subtitle.
- The Structure column is removed from the Library list.
- The row playback control sits on the left, appears only on hover, and shows Pause for the active broadcast.
- Dates are bold and split across day and remaining-date lines.
- The search glyph is larger and centered.
