# Radio Vault v0.31.0 Beta 1 — WPF-Independence Proof

Build identity: `0.31.0-beta1-wpf-independence-proof`

## Scope

Beta 1 is the feature-frozen proof build for Core Hardening. It preserves the accepted Alpha 6 Buildfix 1 runtime behavior and adds executable evidence that the mature backend can support a replacement desktop presentation.

## Hard guarantees

- Nine neutral projects target non-Windows .NET and contain no Windows UI references.
- `TheRadioVault.Application` references only `TheRadioVault.Core`.
- The current WPF and Windows adapter projects are the only intentional Windows boundaries.
- Startup, ordered shutdown, local/remote transitions, local/remote playback, progress protection, natural completion and remote synchronization have explicit Application owners.
- Windows shell integration and local media construction are behind platform ports/factories.
- Direct WPF engine commands, direct concrete media/session construction and legacy WPF-owned remote synchronization state are rejected.
- Remote Now Playing retains authoritative server details and cache-safe fallback behavior.

## What remains WPF-owned

The current windows, XAML, visual resources, navigation, dispatcher-bound presentation and feature-specific screen orchestration remain in WPF until the Avalonia rebuild. Beta 1 records these as explicit presentation work packages rather than pretending they are already portable UI.

## Compatibility

Database schema **45**, LAN capability generation **14**, API **v1**, web-shell generation **10**, shell cache **v33**, IndexedDB **v2**, audio/artwork cache **v1**, pairing credentials and encrypted client cache remain unchanged.
