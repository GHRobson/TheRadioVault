# v0.32.0 Alpha 7 static validation boundary

The package is statically validated before handoff for:

- XML/XAML/AXAML/project parsing;
- JSON parsing;
- solution and project-reference integrity;
- Avalonia event-handler resolution;
- Library List/Grid and broadcast-information binding markers;
- Now Playing and Settings & Tools route/composition markers;
- local/remote `IBroadcastDetailsService` registration;
- absence of SQLite references in remote adapters;
- schema 45, LAN generation 14 and API v1 identity preservation;
- complete SHA-256 source manifest;
- ZIP integrity and Windows/OneDrive-safe internal paths.

Static validation cannot replace the Windows Avalonia compiler or live local/remote interaction tests. Those remain explicit acceptance gates.
