# Radio Vault v0.31.0 Alpha 2 — Application-Service Extraction

Build identity: `0.31.0-alpha2-application-service-extraction`

## Scope

Alpha 2 is the first Core Hardening build to redirect live WPF workflows through the platform-neutral Application layer. It deliberately avoids feature, schema, LAN protocol and visual changes.

## Extracted orchestration

### Startup mode

`ApplicationStartupCoordinator` now owns the policy for choosing local-library or remote-client mode from the launch override and saved Connected Access state. `MainWindow` consumes an `ApplicationStartupPlan` instead of reproducing the policy inline.

### Composition root

`App` creates an `ApplicationServiceRegistry`. `WindowsApplicationServiceRegistration` registers the WPF dispatcher, notification, file-selection, clipboard and application-lifetime adapters. Stateful startup, shutdown and window-transition coordinators are resolved through the same composition root.

### Shutdown

`ApplicationShutdownCoordinator` owns once-only execution, ordered cleanup, per-step failure isolation and a structured result. The current WPF window still supplies concrete actions such as stopping timers, synchronization, progress persistence, web hosting, jobs and playback. The accepted 12-second watchdog and shutdown ordering are unchanged.

### Local/remote transitions

`ApplicationWindowTransitionCoordinator` prevents duplicate transition requests and records source and target session modes. The existing local → remote and remote → local replacement-window behaviour is retained.
