# Radio Vault v0.32.0 Alpha 9 — Dashboard, Archive Navigation & Search UX

## Purpose

Alpha 9 applies the whole-app UX principles from Alpha 8 to the information architecture itself. Top-level navigation is reserved for frequent user goals; supporting configuration is moved into Settings; archive browsing follows time rather than a generic tile grid; and the Dashboard is organised around the action a listener is most likely to take next.

## Navigation

- Dashboard remains first.
- Library remains expandable and exposes the real shows in the archive.
- Search and Favourites are dedicated destinations.
- Moments and Research remain available as focused workspaces.
- Connected Access is embedded in Settings.
- Now Playing is last and contains the Queue.
- Old `queue` and `connected-access` routes redirect safely to their new homes.

## Library archive mode

Grid mode is no longer a flat artwork wall. It is a chronological drill-down inspired by the accepted WPF workflow:

1. choose a year;
2. choose a month;
3. browse that month's broadcasts as a readable list.

Year and month cards show total broadcasts, completed broadcasts, favourites and percentage listened. The hierarchy works for All broadcasts and for a selected show. Search or a listening collection switches to List mode because those tasks need direct results rather than chronological navigation.

## Dashboard

- The latest unfinished broadcast is presented as the featured, likely next action.
- The next four unfinished broadcasts remain immediately available beneath it.
- Recently added is limited to five items.
- Surprise me is restored.
- On this day presents one broadcast card at a time and advances every eight seconds, with manual previous/next controls.

## Search and collections

The dedicated Search workspace searches across shows, titles, dates, descriptions, people and topics. Before a query is entered it exposes real shows plus useful collections such as Continue listening, Favourites, On this day, Recently added and Unplayed.

## Compatibility boundaries

There is no database migration. Schema 45, LAN generation 14, API v1 and all pairing, certificate and encrypted-cache identities are unchanged. Existing local and remote ownership safeguards remain in force.
