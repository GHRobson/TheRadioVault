# Radio Vault v0.29.0 Alpha 3 — Offline Storage & Sync Hardening

Version: `0.29.0-alpha3-offline-storage-sync-hardening`

Alpha 3 makes the Anywhere client resilient when the server disappears.

## Delivered

- IndexedDB schema 2 with a durable mutation journal for offline favourites, listening status and queue additions.
- Existing progress records participate in the same compact sync-state presentation.
- Deterministic last-intent coalescing for repeated favourite and listening-status changes.
- Automatic replay after reconnect, with bounded retry information retained locally.
- Compact accessible sync icons: green tick, animated orange arrows, red offline mark and amber attention mark.
- Tappable status sheet with pending counts and manual Sync now action.
- Collapsed iPhone Library filters with a single search row, Filter button, active-filter badge and preserved selections.
- Secure shell cache v28 while audio/artwork caches remain v1.
- Database schema remains 45.

## Device acceptance

Download single-file and multipart broadcasts, stop the server, reopen Safari, play and seek offline, change favourite/listening state and queue an item, then restart the server and verify each pending intent is applied once. Confirm the Library exposes its broadcast list immediately with advanced filters collapsed.
