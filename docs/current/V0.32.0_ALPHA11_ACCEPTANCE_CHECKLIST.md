# Radio Vault v0.32.0 Alpha 11 acceptance checklist

Build identity: `0.32.0-alpha11-buildfix4-web-playback-nullable-episode-id`

## Build and startup

- Extract the source into a fresh local folder.
- Run `BUILD-AND-RUN.cmd`.
- Confirm Avalonia builds and opens without a startup exception.
- Confirm an existing schema-45 library opens without migration or re-adoption.

## Settings

- Open Settings and navigate through Archive, Playback, Appearance, Connected Access, Radio Vault Anywhere, Transcription and Advanced.
- Confirm the Settings heading scrolls with the page and the sub-navigation remains usable.
- Confirm local archive-folder actions, Archive Health and backup actions are unavailable on a connected client rather than writing to its local database.
- Confirm theme changes still apply immediately.

## Radio Vault Anywhere — authoritative installation

- Save server display name, HTTP/HTTPS and discovery-port settings.
- Start and stop hosting.
- Open or copy the private web link.
- Open the secure phone/tablet setup page.
- Generate a desktop pairing code and pair a client.
- Revoke a paired client.
- Regenerate the private link and confirm the previous token no longer works.
- Run secure diagnostics and, on a test installation, verify certificate reset behaviour.

## Regression checks

- Play and seek a broadcast through Avalonia.
- Close Radio Vault and confirm the final position resumes after relaunch.
- Confirm a v0.31 authoritative server still receives the corrected progress write.
- Confirm Dashboard, Library, Favourites, Moments, Now Playing and Research remain usable.
- Confirm Research pack import/export and authoritative-audit behaviour remain intact.
