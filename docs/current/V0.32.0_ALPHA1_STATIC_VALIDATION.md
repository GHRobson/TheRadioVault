# Radio Vault v0.32.0 Alpha 1 static validation

## Package preparation validation

The generated source package was checked for:

- 45 well-formed project/WPF XAML/Avalonia AXAML XML files (13 project files, 28 WPF XAML files and 4 Avalonia AXAML files);
- complete solution entries for the new Presentation and Avalonia projects;
- exact v0.32 Alpha 1 version alignment in both desktop project files;
- toolkit-neutral Presentation boundaries;
- absence of WPF references from the Avalonia project;
- required Avalonia adapters, composition markers and Dashboard/Library vertical-slice files;
- retained database schema 45 and LAN capability generation 14;
- retained API, pairing and cache identities;
- all 394 XAML event references resolving to C# handlers;
- a regenerated 656-file SHA-256 source manifest and clean ZIP integrity.

## Environment limitation

The packaging environment does not contain the .NET SDK or Windows desktop toolchain. It therefore cannot restore Avalonia packages, compile either desktop shell or run the PowerShell release gate. Those are explicit Windows acceptance steps in `V0.32.0_ALPHA1_ACCEPTANCE_CHECKLIST.md`.

The source package must not be treated as build-accepted until `RUN-RELEASE-GATE.cmd` passes on the user's Windows machine.
