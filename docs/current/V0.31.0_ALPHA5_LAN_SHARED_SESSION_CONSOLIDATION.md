# Radio Vault v0.31.0 Alpha 5 — LAN and Shared-Session Consolidation

Build identity: `0.31.0-alpha5-lan-shared-session-consolidation`

## Purpose

Alpha 5 preserves the accepted Alpha 4 UI, playback, database and remote-client behaviour while moving remote Library session policy out of WPF presentation code.

## Extracted ownership

`RemoteLibrarySessionCoordinator` now owns:

- the server synchronization cursor (`sessionId`, change sequence and Library revision);
- single-flight synchronization and duplicate request suppression;
- linked cancellation and bounded request timeouts;
- live, updating, cached read-only, unavailable and closing states;
- bounded exponential reconnect scheduling;
- last-sync timing, mode, changed-row and error diagnostics;
- cached-session adoption and orderly shutdown cancellation.

`MainWindow` remains responsible for applying returned broadcast, queue, transcript, Moment, settings and Research data to the current WPF controls. Certificate-pinned HTTP transport remains in the existing LAN adapter. This is an ownership extraction, not a protocol or feature change.

## Live integration

The same session lifecycle is used by cached startup, initial server connection, six-second change polling, Settings cache refresh, manual reconnect and shutdown. The prior WPF-local semaphore, synchronization cancellation source, cursor fields, failure counter, retry timestamp and diagnostic fields have been removed.

- Database schema: **45**
- LAN capability generation: **14**
- API: **v1**
- Pairing credentials: unchanged
- Encrypted desktop cache identity: unchanged
- Web shell, IndexedDB, audio and artwork cache identities: unchanged
