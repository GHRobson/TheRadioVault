# Radio Vault v0.32.0 Alpha 5 acceptance checklist

- [ ] `BUILD-AND-RUN.cmd` restores, builds and launches the Avalonia shell.
- [ ] Research overview counts load without delaying startup indefinitely.
- [ ] Search, show, status and review filters work together.
- [ ] Research records display show, date, confidence, evidence counts and attention state.
- [ ] Selecting a record loads all saved scalar fields, people, topics and sources.
- [ ] Empty fields remain visually empty.
- [ ] Metadata Studio changes survive navigation and restart.
- [ ] Linked archive metadata updates without changing database schema.
- [ ] Manual provenance rows are written for edited fields.
- [ ] Artwork can be selected/cleared for linked local records and is disabled for unlinked records.
- [ ] Source URLs open externally and source-less records do not expose a broken action.
- [ ] Source diagnostics and import history remain read-only.
- [ ] Local playback, favourites, Queue, Moments and Library show navigation still work.
- [ ] Elastic scrolling remains responsive and jitter-free.
- [ ] Application shutdown persists playback progress and leaves no process behind.
