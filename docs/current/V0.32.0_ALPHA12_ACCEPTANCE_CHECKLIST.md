# Radio Vault v0.32.0 Alpha 12 — Acceptance checklist

Build identity: `0.32.0-alpha12-research-coverage-undated-broadcasts-polish`

## Build

- [ ] Run `BUILD-AND-RUN.cmd` on the accepted Windows development machine.
- [ ] Confirm the Avalonia Release build succeeds with no new warnings treated as errors.
- [ ] Confirm startup succeeds against the existing schema-45 library without migration or re-adoption.

## Now Playing and Dashboard

- [ ] With nothing playing, open Now Playing and confirm the existing queue remains visible and usable.
- [ ] Confirm On This Day, Recently Added and Unheard Broadcasts contain play actions but no favourite buttons.
- [ ] Confirm missing artwork uses the radio-mast glyph on Dashboard, Library, Now Playing, mini-player, Broadcast Info and Research.

## Library

- [ ] In list view, toggle the checkmark beside the listening filter and confirm completed broadcasts disappear.
- [ ] Confirm the result text reports the hidden count.
- [ ] Confirm the checkmark is absent in chronological grid view and Clear Filters resets it.

## Research — undated broadcasts

- [ ] Confirm the Undated Broadcasts mode lists audio with absent, Unknown or Ambiguous dates.

- [ ] Rescan the library and confirm the manual date remains unchanged with `Manual` confidence.
- [ ] Repeat through a connected Avalonia client and confirm the server library is changed, not the client cache.

## Research — coverage heatmap

- [ ] Select each major show and confirm the complete dated run renders by year.
- [ ] Spot-check weekday gaps, known missing recordings, thin metadata and strong metadata against underlying broadcasts.
- [ ] Confirm the heatmap remains usable with long-running shows and horizontal/vertical scrolling.
- [ ] Repeat through a connected Avalonia client and confirm the data is server authoritative.

## Regression

- [ ] Confirm local playback, resume persistence and v0.31-server fallback behaviour remain correct.
- [ ] Confirm Settings and Radio Vault Anywhere remain functional.
