# Radio Vault v0.30.0 Alpha 3 acceptance checklist

Use the server as the server and the remote client as the paired client.

## Build and connection

- [ ] Build succeeds on both Windows PCs.
- [ ] Existing Alpha 1 pairing remains valid without creating a new code.
- [ ] The client title bar shows an orange connecting icon and then a green connected icon.
- [ ] Clicking the icon opens Connected access settings.
- [ ] Closing the server changes the client icon to red without freezing the app.
- [ ] Restarting the server returns the icon to green without re-pairing.

## Remote Library writes

- [ ] Open **Server Library** and search the full server catalogue.
- [ ] Favourite a broadcast on the remote client and confirm it becomes favourite on the server.
- [ ] Remove the favourite from either PC and confirm the server state reloads correctly.
- [ ] Mark a broadcast listened and unlistened from the remote client.
- [ ] Add a broadcast to the server queue.
- [ ] Open the Queue tab, remove one item, then clear the queue.
- [ ] Confirm the server queue reflects each change.

## Playback

- [ ] Start a normal single-part broadcast from the remote client.
- [ ] Pause, resume, skip backward, skip forward and seek.
- [ ] Change playback speed.
- [ ] Start a known multipart broadcast and confirm the next part begins automatically.
- [ ] Seek across a multipart boundary and confirm playback opens the correct part.
- [ ] Confirm no Windows Firewall prompt is required for the loopback media bridge.

## Progress authority

- [ ] Play at least 30 seconds on the remote client and close the Server Library window.
- [ ] Confirm the server shows the same or newer position.
- [ ] Reopen the client and confirm Resume begins at the server position.
- [ ] Seek backward on the remote client, play briefly, close the window and confirm the backward seek becomes the new resume point.
- [ ] Play to the end and confirm the server broadcast becomes Completed.

## Failure handling

- [ ] Stop the server during playback; the client reports a playback or progress connection error without crashing.
- [ ] Restart the server and start playback again without re-pairing.
- [ ] Revoke the client and confirm the title icon becomes amber and writes are rejected.
- [ ] Pair again and confirm normal operation returns.
