# v0.31.0 Alpha 1 Buildfix 2 static validation

Target version: `0.31.0-alpha1-architecture-baseline-buildfix2`

## Build-failure analysis

The second Windows build reported eight `CS0234` errors in existing WPF files. Every error had the same cause: after introducing the sibling namespace `TheRadioVault.Application`, a bare `Application.Current` could resolve as a namespace member lookup rather than WPF's application singleton.

All active occurrences in `TheRadioVault` and `TheRadioVault.Platform.Windows` are now explicitly qualified as `global::System.Windows.Application.Current`. A source-wide regression check rejects a bare occurrence in either project, and the older remote-playback dispatcher assertion now expects the qualified expression.
