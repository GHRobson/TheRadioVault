# Radio Vault v0.30.0 Alpha 9 acceptance checklist

## Build and connection

- [ ] `Release | x64` builds from `0.30.0-alpha9-parity-audit-hardening-buildfix2`.
- [ ] Server and remote client report database schema 45 and capability generation 14.
- [ ] The remote client requires `lan.parity-audit` and `lan.research-workspace`.
- [ ] Existing Alpha 8 pairing and encrypted cache upgrade without local-library changes.

## Parity contract

- [ ] Connected Access → **Remote-client parity** reports every published surface available.
- [ ] Refresh updates the timestamp/revision without disrupting the current page.
- [ ] Copy diagnostics produces server identity, version, API, capability generation, Library revision, change sequence and per-surface status.

## Metadata and artwork

- [ ] Library artwork matches the server where artwork exists.
- [ ] Broadcast Info and Metadata Studio load the same artwork and metadata as the server.
- [ ] Metadata edits made remotely appear on the server and another remote client after synchronization.
- [ ] Remote Metadata Studio never opens or alters the remote client's local database.
- [ ] Headline-review and artwork-file replacement are clearly identified as server-owned.

## Research

- [ ] Research overview counts match the server.
- [ ] Find Broadcast, filters, record details, people, topics, sources, Moments and conflicts load from the server.
- [ ] Source diagnostics and import history match the server.
- [ ] Global search can find a server Research record and navigate to it.
- [ ] Research pack import/export still completes against the server.
- [ ] Reconciliation, repair and rollback actions cannot write to the remote client's local database.

## Existing Alpha 8 regression

- [ ] Cached startup, incremental synchronization and live updates still work.
- [ ] Server loss remains read-only and never silently switches libraries.
- [ ] Reconnection and streamed-audio recovery still work.
- [ ] Playback, queue, favourites, Moments, transcripts and Settings remain functional.

## Daily-driver gate

- [ ] Use the remote client for at least one normal listening session with metadata and Research activity.
- [ ] No unexplained difference remains outside `V0.30.0_ALPHA9_PARITY_MATRIX.md`.
- [ ] No crash, local-database leakage, duplicate write or stale playback-control state is observed.
## Buildfix 2 shutdown acceptance

- [ ] Local-library mode exits while idle, paused and playing.
- [ ] Remote-client mode exits while idle, paused and playing.
- [ ] Remote-client mode exits with the server unavailable or reconnecting.
- [ ] Repeated closes remove the Radio Vault process from Task Manager within 12 seconds.
- [ ] Reopening preserves listening progress, with the previous periodic server save used if the final two-second mutation could not finish.
- [ ] `diagnostic.log` records orderly `Shutdown` stages and does not show a repeated or re-entrant close sequence.
