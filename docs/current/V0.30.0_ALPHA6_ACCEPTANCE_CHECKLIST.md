# v0.30.0 Alpha 6 acceptance checklist

## Build and startup

- [ ] Build `Release | x64` on the server and remote client.
- [ ] Both local and remote-client modes open the ordinary `MainWindow`.
- [ ] The client verifies capability generation 12.

## Remote Research import

- [ ] Open Research on the remote client and choose Import research pack.
- [ ] Select a `.trvpack` stored on the remote client.
- [ ] Upload progress appears, followed by the normal preview dialog.
- [ ] Cancel from the preview and confirm no server changes are made.
- [ ] Repeat and apply the import; confirm the result summary appears.
- [ ] Import the same package again and confirm the preview recognises its server package hash/history.
- [ ] Start a test import, cancel it while applying, and confirm the server transaction rolls back without partial research changes.
- [ ] Confirm imported research appears in server data and in refreshed remote-client broadcast details.
- [ ] Confirm the remote client's local-library database remains unchanged.

## Remote Research export

- [ ] Choose a show/year through the normal export dialog on the remote client.
- [ ] Save the `.trvpack` to a remote-client folder.
- [ ] Confirm the package opens and contains server research.

## Remote Settings

- [ ] Archive shows the server's folders, broadcasts, files, storage, preservation and backup age.
- [ ] Folder editing, scanning, metadata-file synchronization and backup creation are not shown.
- [ ] Change playback skip intervals on the remote client and apply them.
- [ ] Reopen Settings on server and remote client and confirm the values match.
- [ ] Connected access shows only client connection/trust/recovery controls.
- [ ] Radio Vault Anywhere/server-hosting controls are absent.
- [ ] Transcription and Advanced do not appear in the remote Settings navigation.
- [ ] Use local-library recovery and confirm full local Settings return.

## Regression

- [ ] New scans still promote trustworthy broadcasts into the canonical Library.
- [ ] Normal and multipart remote playback work.
- [ ] Progress, favourites, queue, Moments and metadata still write through.
