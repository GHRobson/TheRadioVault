# Radio Vault v0.32.0 Alpha 1 Buildfix 4 — Avalonia XAML compatibility

Build identity: `0.32.0-alpha1-buildfix4-avalonia-default-shell`

## Windows XAML compiler findings

The third Windows build reached Avalonia's XAML compiler and exposed two invalid `Grid.Padding` assignments in `LibraryView.axaml`. `Grid` is a layout panel and does not provide a `Padding` property. The same build also reported that Avalonia 12 retains `TextBox.Watermark` only as an obsolete compatibility alias.

## Corrections

- The Library table header is now a padded `Border` containing its column `Grid`.
- Each Library result row is now a padded `Border` containing its column `Grid`.
- The search field now uses `PlaceholderText`.
- Source validation now rejects `Padding` on any Avalonia `Grid` and rejects `Watermark` on Avalonia `TextBox` controls.

Buildfix 2 lifetime aliases and Buildfix 3 constructor/root-namespace corrections remain intact. These are shell compile repairs only. Database schema 45, LAN capability generation 14, API v1, pairing, certificates and cache identities are unchanged.
