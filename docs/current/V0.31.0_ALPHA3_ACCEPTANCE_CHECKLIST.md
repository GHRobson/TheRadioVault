# Radio Vault v0.31.0 Alpha 3 acceptance checklist

Target: `0.31.0-alpha3-windows-platform-abstraction`

## Build and architecture gate

- [ ] Extract to a fresh short local path.
- [ ] Build `Release | Any CPU` in Visual Studio 2022/.NET 8.
- [ ] Run `validate-source.ps1`; source and architecture validation pass.
- [ ] Run `release-gate.ps1`; regression tests pass and compiled ProductVersion begins with the target identity.
- [ ] Confirm `artifacts/architecture/architecture-report.json` reports zero violations and architecture version `0.31-alpha3`.
- [ ] Confirm direct Process.Start, Clipboard, Registry and SystemParameters marker counts are zero for the WPF project.

## File and folder selection

- [ ] Add Archive Folder opens the folder picker and imports the selected folder through the existing collection chooser.
- [ ] Create Backup proposes the normal filename and backup directory and produces a restorable `.trvbackup`.
- [ ] Restore Backup selects and restores a valid backup after confirmation.
- [ ] Metadata export/import selects the expected package types and preserves existing results.
- [ ] Transcription executable, model and VAD browse buttons select the expected files.
- [ ] Cancelling any migrated picker causes no change or error.

## Clipboard and external launching

- [ ] Local and remote broadcast web links copy correctly.
- [ ] Web access links, secure setup links and LAN pairing codes copy correctly.
- [ ] Research source lists and remote parity diagnostics copy correctly.
- [ ] Double-clicking a valid HTTP/HTTPS Research source opens it in the default browser.
- [ ] Reveal in Explorer selects the correct audio file.
- [ ] Data folder, transcription models folder and crash log open normally.
- [ ] Database reset relaunches Radio Vault and closes the outgoing process.

## Theme, window placement and regressions

- [ ] Dark, Light and System theme modes behave as before.
- [ ] A saved visible window position restores normally.
- [ ] An off-screen saved position is ignored and the window remains accessible.
- [ ] Local/remote startup, transitions, playback and shutdown remain as accepted in Alpha 2.
- [ ] No database migration, pairing reset or remote-cache reset occurs.
