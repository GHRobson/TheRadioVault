# Radio Vault v0.32.0 Alpha 11 — Settings and Radio Vault Anywhere parity

Build identity: `0.32.0-alpha11-buildfix4-web-playback-nullable-episode-id`

## Scope

Alpha 11 closes the principal Settings parity gap before Beta. The Avalonia Settings page now provides task-focused sections for Archive, Playback, Appearance, Connected Access, Radio Vault Anywhere, Transcription and Advanced information.

Local authoritative installations can inspect Archive Health, manage archive roots, create or restore guarded backups, configure playback and transcription preferences, and host the existing Radio Vault Anywhere web companion. Hosting controls include HTTP/HTTPS settings, automatic startup, private access/setup links, desktop pairing, paired-client revocation, private-link rotation, certificate reset and secure diagnostics.

Connected clients retain their own Connected Access controls but present server-owned guidance for archive administration, transcription and Radio Vault Anywhere hosting.
