# Radio Vault v0.30.0 Alpha 5 — superseded implementation note

The initial Alpha 5 source introduced a separate remote-client window. It compiled successfully but was rejected because a remote client must be indistinguishable from a local Radio Vault installation.

Do not use the separate-shell architecture described by the original release. Alpha 5 Buildfix 1 removes those windows and runs server services behind the existing `MainWindow` instead. See `V0.30.0_ALPHA5_BUILDFIX1_UI_PARITY.md`.
