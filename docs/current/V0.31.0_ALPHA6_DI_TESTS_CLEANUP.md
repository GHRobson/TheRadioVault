# Radio Vault v0.31.0 Alpha 6 Buildfix 1 — dependency injection, tests, cleanup and remote Now Playing parity

Build identity: `0.31.0-alpha6-di-tests-cleanup-buildfix1`

## Purpose

Alpha 6 Buildfix 1 is the accepted final Core Hardening alpha plus a remote Now Playing parity repair. It preserves the accepted Alpha 5 application behaviour while making service composition deterministic, diagnosable and harder for presentation code to bypass.

## Composition hardening

`ApplicationServiceRegistry` now records explicit singleton and transient lifetimes. It supports lazy singleton factories, rejects duplicate registrations, detects dependency cycles, produces a required-service report, freezes after startup and disposes created singleton services in reverse registration order.

Before Radio Vault opens its first window, `App` verifies all required application and Windows platform services, freezes the dependency graph and writes a concise composition record to `diagnostic.log`. A missing registration therefore fails at the composition edge rather than much later inside a feature workflow.

## Playback construction boundary

Local media creation now enters through the platform-neutral `ILocalPlaybackEngineFactory`. `TheRadioVault.Platform.Windows` supplies `WpfMediaPlaybackEngineFactory`, while `PlaybackSessionFactory` in the Application project owns playback-session construction. `MainWindow` still chooses local or certificate-pinned remote playback at the composition edge, but it no longer constructs the WPF media adapter or `PlaybackSessionCoordinator` directly.

## Lifecycle cleanup

The shared `RemoteLibrarySessionCoordinator` is now explicitly disposed by the ordered shutdown pipeline after active synchronization is stopped. This applies to ordinary shutdown and local/remote replacement-window cleanup.

## Remote Now Playing parity

The remote desktop shell no longer asks its isolated cache database for server-owned broadcast knowledge. It first renders synchronized Library fields so live and cached sessions never present an empty page, then enriches live Now Playing with the server broadcast-details contract: station, slot, multipart identity, role-separated people, topics, archive notes, Moments and certificate-specific cached artwork. Per-request cancellation and generation checks prevent stale details after rapid playback changes or window shutdown.

## Regression expansion

The neutral console suite now verifies:

- required-service composition reporting;
- registration freezing;
- lazy singleton creation and identity;
- reverse-order singleton disposal and idempotent registry shutdown;
- cyclic dependency rejection;
- application-owned playback-session construction;
- all previously accepted startup, shutdown, playback and LAN-session policies.
