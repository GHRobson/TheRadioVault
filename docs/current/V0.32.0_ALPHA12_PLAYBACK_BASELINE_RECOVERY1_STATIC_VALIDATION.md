# Alpha 12 Playback Baseline Recovery 1 — static validation

## Recovery boundary

This package starts from the Alpha 12 Buildfix 5 source previously built on the user's Windows machines. It does not extend the transactional handoff repair branch. Desktop transfer presentation and prepare/ready/commit operations are disabled while ordinary server and remote-client playback are validated independently.

## Source checks

- Project, AXAML, XAML and XML documents parse as XML.
- Packaged JSON documents parse successfully.
- Modified C# files have balanced lexical delimiters and implement every `IPlaybackHandoffService` member.
- Avalonia composition registers the ownership-only adapter on a remote client and the null adapter on the local server shell.
- Desktop handoff presentation is forced off.
- Remote media-manifest and durable-progress requests use the isolated playback connection channel.
- Returning remote clients open from encrypted cache before background Library synchronisation.
- No merge-conflict markers, symbolic links, unsafe archive paths or bundled build-output directories are present.

## Runtime acceptance still required

This environment does not contain the .NET 8 Windows/Avalonia toolchain or an audio device. `BUILD-AND-RUN.cmd` on Windows remains the authoritative compilation and decoder test.
