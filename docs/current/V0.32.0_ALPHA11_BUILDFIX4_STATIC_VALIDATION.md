# Alpha 11 Buildfix 4 static validation

Build identity: `0.32.0-alpha11-buildfix4-web-playback-nullable-episode-id`

## Compile failure corrected

The reported `CS0173` in `AvaloniaWebPlaybackController.CreateState` came from this inferred conditional expression:

```csharp
var episodeId = hasBroadcast ? currentBroadcastId : null;
```

`currentBroadcastId` is a non-nullable `long`, while the destination contract `WebPlaybackState.EpisodeId` is `long?`. The local is now explicitly declared as nullable:

```csharp
long? episodeId = hasBroadcast ? currentBroadcastId : null;
```
