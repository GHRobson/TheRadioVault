# v0.30.0 Alpha 7 acceptance checklist

## Build and startup

- [ ] Build `Release | x64` on the server and remote client.
- [ ] Local mode opens normally without a skeleton or unnecessary busy overlay.
- [ ] Remote-client mode immediately shows the normal Radio Vault shell with animated skeleton content.
- [ ] The skeleton caption updates while the remote Library loads.
- [ ] The skeleton disappears when the Dashboard is ready and the app never appears as a separate client shell.
- [ ] Stop the server and confirm the client exits the skeleton into a useful unavailable state with Settings/local-library recovery still accessible.

## Remote busy feedback

- [ ] Refresh the server Library and confirm the content loading overlay appears and blocks duplicate clicks.
- [ ] Run a global search and confirm the busy state clears when results appear.
- [ ] Open Broadcast Info and a transcript and confirm each has visible loading feedback.
- [ ] Open remote Settings and confirm the server snapshot displays a loading state before the real values arrive.
- [ ] Import/export research and confirm their established progress windows still work normally.

## Playback startup and buffering

- [ ] Start a normal remote broadcast and confirm the play/pause icon becomes a spinner until the stream is genuinely ready.
- [ ] Confirm skip, seek, speed and Moment controls remain disabled while the initial stream is opening.
- [ ] Confirm the spinner changes directly to Pause once audio begins.
- [ ] Start a multipart broadcast and confirm the next-part transition shows a loading/buffering state without losing playback intent.
- [ ] Briefly interrupt Wi-Fi or server availability and confirm a temporary stall displays buffering rather than Play.
- [ ] Restore the connection and confirm the UI returns to Pause automatically when progress resumes.

## Playback-state drift regression

- [ ] Let a remote broadcast play for at least 30 minutes.
- [ ] Confirm the button remains Pause while audio is advancing.
- [ ] Pause once and confirm audio pauses and the icon changes to Play with one click.
- [ ] Resume once and confirm audio resumes and the icon changes to Pause with one click.
- [ ] Repeat after seeking and after changing playback speed.
- [ ] Confirm Dashboard and Library playback indicators match the actual stream state throughout.

## Regression

- [ ] Alpha 6 remote Research import/export still targets the server database.
- [ ] Alpha 6 mode-aware Settings and synchronized playback preferences still work.
- [ ] New scans still promote trustworthy broadcasts into the canonical Library.
- [ ] Progress, favourites, queue, Moments, metadata and transcript access still write through.
- [ ] The remote client's dormant local library remains untouched while connected remotely.
