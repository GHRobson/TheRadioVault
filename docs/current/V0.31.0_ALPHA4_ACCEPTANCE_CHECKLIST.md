# Radio Vault v0.31.0 Alpha 4 acceptance checklist

Target: `0.31.0-alpha4-playback-media-boundary-cleanup`

## Build and architecture gate

- [ ] Extract to a fresh short local path.
- [ ] Build `Release | Any CPU` in Visual Studio 2022/.NET 8.
- [ ] Run `validate-source.ps1`; source and architecture validation pass.
- [ ] Run `release-gate.ps1`; regression tests pass and compiled ProductVersion begins with the target identity.
- [ ] Confirm the architecture report has zero violations and architecture version `0.31-alpha4`.
- [ ] Confirm the WPF project contains no direct `_playback` command path and the normal WPF media engine is in `TheRadioVault.Platform.Windows`.

## Local playback

- [ ] Start an unplayed local broadcast, pause, resume and stop without changed UI behaviour.
- [ ] Resume a partly heard broadcast and confirm the audible playhead starts at the saved position.
- [ ] Seek backwards and forwards with both sliders and keyboard skip controls.
- [ ] Change playback speed, quit, reopen and confirm the speed and listening position persist.
- [ ] Play a canonical multipart broadcast through at least one automatic segment transition.
- [ ] Seek across a multipart segment boundary in both directions.
- [ ] Let a broadcast naturally enter the configured completion window and confirm completion count increments once.
- [ ] Seek directly into the completion window and confirm that seek alone does not increment completion count.
- [ ] Let playback reach the end and confirm the next queued broadcast advances as before.

## Remote-client playback

- [ ] Start, pause, resume, seek and change speed while connected to the authoritative server.
- [ ] Confirm certificate-pinned multipart playback still changes parts transparently.
- [ ] Confirm periodic progress appears on the server and deliberate backward seeks remain allowed.
- [ ] Disconnect the server during playback and confirm existing recovery/error behaviour remains intact.
- [ ] Reconnect and confirm progress synchronisation resumes.

## Lifecycle and regressions

- [ ] Switch local → remote → local while playback is paused and while no media is loaded.
- [ ] Quit while idle, playing, paused, loading and disconnected; the process exits without hanging.
- [ ] Confirm the final shutdown progress save does not replace a positive position with zero.
- [ ] Confirm Moments and transcript timestamp seeking still land on the expected logical position.
- [ ] Confirm sleep timer, web/phone playback ownership and transfer-to-desktop behaviour remain unchanged.
- [ ] No database migration, library re-adoption, pairing reset or cache reset occurs.
