# Radio Vault 0.33.0 Alpha 2 acceptance

Alpha 2 activates the existing local transcription foundation in the Avalonia application. It does not upload archive audio. The worker and models are installed on demand from their official sources rather than being bundled in every Radio Vault download.

## Basic workspace check

1. Start Radio Vault and open **Transcripts** in the sidebar.
2. Confirm the page opens and explains whether the local worker is ready.
3. Select **Transcription setup** and confirm Settings opens directly to Transcription.
4. Return to Transcripts. Existing transcripts, if any, should appear on the left and recent jobs at the bottom.

## Real local transcription

1. In Settings → Transcription, choose a speech model and select **Install recommended setup**. This downloads the official Windows worker, selected model and VAD model and saves the configuration automatically.
2. Confirm the status reports that the selected model is ready. Manual Browse buttons remain available if you already have compatible files.
3. Play a locally available broadcast and return to Transcripts.
4. Choose **Five-minute sample**. This starts at the current playback position and preserves the result as a Draft transcript.
5. Navigate elsewhere and confirm **Transcribing locally** remains visible at the bottom of the sidebar.
6. Return to Transcripts and select Refresh if needed. Confirm the completed transcript appears.
7. Select a timed phrase and choose **Play selected timestamp**.

## Job safety

- **Cancel selected** requests cancellation of a queued or running job.
- **Retry selected** is available for failed, cancelled and interrupted jobs.
- Closing Radio Vault during a job must not leave it permanently Running; the next launch shows it as Interrupted.

Full-broadcast transcription is available once the sample workflow is confirmed. Existing transcripts are protected from accidental replacement in this first UI slice.
