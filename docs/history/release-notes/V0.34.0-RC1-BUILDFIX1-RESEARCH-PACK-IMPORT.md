# RadioVault 0.34.0 RC1 Buildfix 1 — Research Pack import

This build repairs the native client's Deep Research Pack preview and confirmation workflow.

## What changed

- Transcript-rich packs up to 256 MB can be uploaded to the connected server.
- A LAN upload can take up to ten minutes without being abandoned by the server.
- Invalid, empty, missing and oversized packs produce a persistent explanation on the Research page.
- Server errors retain their diagnostic reference so a remaining problem can be traced.
- The final **Import now** action appears only after the server has successfully analysed the pack.
- A failed analysis can be retried without choosing the file again.

## Acceptance check

1. Install this build on both the server and client computers.
2. Open **Research** and select **Import Deep Research Pack**.
3. Choose a valid `.trvpack`. Confirm the analysis remains visible and **Import now** appears.
4. Select **Import now** and confirm the result appears in Import history.
5. Choose a non-pack ZIP or damaged pack. Confirm the page displays a permanent explanation and **Try again**, with no data imported.
6. Retry after replacing or correcting the selected file and confirm the preview can complete.
7. If available, repeat with a pack larger than 64 MB that contains transcripts.
