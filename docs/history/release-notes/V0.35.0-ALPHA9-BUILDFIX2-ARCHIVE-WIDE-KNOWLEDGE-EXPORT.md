# Radio Vault 0.35.0 Alpha 9 Buildfix 2 — Archive-wide Knowledge export

Knowledge Database export is now unambiguously an archive-wide operation. The old show and year dialog has been removed from the native client, and Radio Vault Web no longer requires a selected show before export.

## Acceptance check

1. Open **Knowledge** in the Client and choose **Export full Knowledge Database…**.
2. Confirm that no show or year prompt appears and save the `.trvknowledge` file.
3. Open Radio Vault Web, visit **Knowledge**, and export the database without selecting a show.
4. Import either exported file into a test Radio Vault database and confirm it contains broadcasts, transcripts and Explore data from multiple shows and years.

The Client and Server should both report `0.35.0-alpha9-buildfix2` before testing the paired path.
