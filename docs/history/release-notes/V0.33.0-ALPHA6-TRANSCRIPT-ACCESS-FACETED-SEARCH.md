# Radio Vault 0.33.0 Alpha 6 — Transcript access and faceted Search

## Included

- Full Broadcast Information shows whether a transcript exists, opens it directly, or starts a full transcription.
- Now Playing provides the same transcript-aware actions for the current broadcast.
- Opening a transcript selects the requested broadcast instead of landing on an unrelated transcript.
- Duplicate active transcription jobs for one broadcast are rejected centrally.
- Search includes content-scope and listening-status chips, show and year selectors, and a Has transcript filter.
- Autocomplete suggests archive shows, broadcast titles, known people and topics.

## Acceptance checks

1. Open Broadcast information for an item with a transcript and choose **View transcript**; confirm the correct transcript is selected.
2. Open an item without a transcript and choose **Start transcription**.
3. In Now Playing, repeat both states using the transcript action beside the playback actions.
4. Search for a person or spoken phrase and restrict the scope using the filter chips.
5. Combine a show, year, listening state and Has transcript filter and confirm the result count updates.
6. Type the beginning of a known show, person or topic and choose an autocomplete suggestion.
