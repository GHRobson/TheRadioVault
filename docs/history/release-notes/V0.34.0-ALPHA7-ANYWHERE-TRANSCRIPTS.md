# Radio Vault v0.34.0 Alpha 7 - Anywhere transcripts

Alpha 7 begins the native-style Radio Vault Anywhere rebuild with a complete Transcripts destination. The browser and native client now read the same saved transcripts and control the same server-owned transcription jobs and batches.

## Acceptance

1. Replace both the Alpha 6 server and client with the matching Alpha 7 builds, then start RadioVault Server followed by Radio Vault.
2. Open Radio Vault Anywhere and refresh once if it was already installed. Confirm the new teal **Transcripts** destination appears.
3. Open **Transcripts** and confirm the server setup status, saved transcript count and existing transcript list load.
4. Select a transcript, play a timed phrase, search by broadcast title/show and export TXT, SRT and VTT files.
5. Open a broadcast's information page and queue both a five-minute sample and a full-broadcast transcription as appropriate.
6. On **Individual jobs**, confirm live progress and pause, resume, retry and cancel controls appear only when allowed.
7. On **Batch runs**, expand a batch to see its broadcasts and confirm pause, resume, retry-failed and cancel controls.
8. Confirm native playback, Anywhere playback and handoff continue from the same broadcast and position.

Existing downloaded audio and artwork remain on the browser device when the secure shell advances to cache v38.

## Next roadmap slice

Continue rebuilding Anywhere around the native information architecture and surface the next hidden client areas, beginning with Search and Research while retaining the accepted shared server and handoff boundaries.
