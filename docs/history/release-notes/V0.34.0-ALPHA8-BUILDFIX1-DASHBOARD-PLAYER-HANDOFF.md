# Radio Vault v0.34.0 Alpha 8 Buildfix 1 - Dashboard, player and handoff

This buildfix closes the two visible native-parity gaps in Alpha 8 and fixes the transactional phone handoff race captured by the Alpha 8 playback diagnostic.

## Acceptance

1. Replace both Alpha 8 applications with the matching Buildfix 1 server and client, starting the server first.
2. Open Radio Vault Anywhere and refresh once so shell cache v40 is installed.
3. Confirm the Dashboard follows the native layout: featured Continue Listening, Surprise Me, Broadcasts, In progress, Completed, Favourites, Up next, On this day, Recently added and Unheard broadcasts.
4. Confirm Dashboard play, Resume, Surprise Me, information and On This Day carousel controls work.
5. Confirm the desktop bottom player matches the native three-column bar, including Favourite, Moment, information, speed, more actions and volume.
6. Confirm the phone Dashboard collapses cleanly to one column and the compact player remains visible without covering the last controls.
7. While a broadcast is playing in the native client, move playback to Anywhere. Confirm the transfer completes at the live source position without the stale-playhead diagnostic.

The original output remains authoritative until the target decoder is ready, freshly aligned and committed. A failed move still leaves the original output unchanged.
