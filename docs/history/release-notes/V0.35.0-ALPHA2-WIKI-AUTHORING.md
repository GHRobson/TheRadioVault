# Radio Vault 0.35.0 Alpha 2 — Wiki authoring

Alpha 2 turns the Wiki database introduced in Alpha 1 into a usable reading and authoring workflow.

## What is included

- Wiki pages open in a clean reading mode. Editing is an explicit mode with the article, evidence and timeline tools separated from normal reading.
- **Build starter Wiki** creates draft pages for archive shows, recurring people and recurring topics. Generation is repeatable and never changes a page that already exists.
- Citations can be created and edited with source title, type, author, publisher, URL, publication date, locator, quotation and support note.
- Images can be attached with a caption, alt text, creator, copyright holder, licence, captured date and the historical period represented.
- Timeline events can be dated, ranked by significance and linked through archive search to exact broadcasts or Moments.
- Exported `.rvwiki` packages include `archive-context.json`, containing stable archive IDs, show/broadcast catalogue data, known people/topics and transcript availability. It is context for an authoring agent, not automatically trusted prose.
- Import preview lists every incoming page as Added, Changed, Unchanged or Protected. A page edited by a human after export remains protected and is skipped.

## Upgrade and compatibility

- Database schema remains **46**; no Wiki or Library migration is required.
- Connected capability generation is **38**. Install the matching Server and Client before testing remote Wiki authoring.
- Pairing, certificates, encrypted caches, media identity, Research packs and playback handoff are preserved.
- `.rvwiki` schema remains version 1. Alpha 1 packs remain readable; the archive context file is optional on import.

## Acceptance pass

1. Open Wiki and confirm an existing page opens in **Read** mode; choose **Edit** to reach the authoring tabs.
2. Choose **Build starter Wiki** once and confirm draft show/person/topic pages appear. Choose it again and confirm no pages are duplicated or overwritten.
3. Add a citation, dated image and timeline event, link a broadcast or Moment, then save and reopen the page.
4. Export an authoring pack and confirm it contains `archive-context.json` as well as Markdown, citations, image metadata and timeline JSON.
5. Edit a page after export, then preview an older changed pack and confirm that page is labelled **Protected** before import.
