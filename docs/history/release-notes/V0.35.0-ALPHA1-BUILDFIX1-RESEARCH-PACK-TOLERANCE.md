# Radio Vault 0.35.0 Alpha 1 Buildfix 1

This buildfix repairs Deep Research Pack imports completed by external AI agents when their JSON is semantically correct but uses a harmless scalar variation.

## Fixed

- A single string is accepted where a text-list field such as `sources[].supports` normally uses an array.
- Numeric and Boolean scalar metadata is accepted where a textual audit field is expected.
- Radio Vault still exports the canonical schema: text lists become arrays and scalar metadata becomes text.
- A genuinely incompatible nested value now reports its precise JSON path in the Research import panel.

## Verified supplied packs

- The Ron & Ron Show: 21 records previewed and transactionally stored.
- Bennington: 914 records previewed and transactionally stored.
- Ron Bennington Interviews: 604 records previewed and transactionally stored.

All verification imports used disposable databases and did not change the live archive.

## Acceptance check

Install the updated Server on the authoritative library computer and the matching Client on remote computers. In Research, choose each completed `.trvpack`, confirm that the preview remains visible, select **Import now**, and confirm that the final result reports stored, matched, retained-missing and conflict counts.
