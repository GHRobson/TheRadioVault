# Radio Vault v0.34.0 Alpha 8 Buildfix 2 - Audible and paused playback

This buildfix corrects two Radio Vault Anywhere player regressions introduced with the native-style bottom player.

## Acceptance

1. Replace both applications with the matching Buildfix 2 server and client, starting the server first.
2. Open Radio Vault Anywhere and refresh once so shell cache v41 is installed.
3. With no previously saved Anywhere volume setting, start a broadcast and confirm it is audible immediately at full volume.
4. Adjust the volume, refresh the page and confirm the chosen level is retained.
5. Play a broadcast in Anywhere, pause it, and leave it paused for at least 45 seconds.
6. Confirm the player remains paused on this web client and does not change to the handover interface while the page remains open.
7. Confirm moving playback deliberately between Anywhere and the native client still works in both directions.

The server now treats pause as playback state rather than output abandonment. A five-second browser presence heartbeat keeps the selected output alive; closing or suspending the browser still allows the existing stale-client timeout to release it.
