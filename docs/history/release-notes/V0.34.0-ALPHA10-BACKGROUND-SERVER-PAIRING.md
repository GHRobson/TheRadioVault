# Radio Vault v0.34.0 Alpha 10 - Background server and native pairing

Alpha 10 productises Radio Vault Server as the long-running archive owner and establishes the secure trust relationship required by remote native clients.

## What changed

- Radio Vault Server is single-instance and remains active when its settings window closes.
- The native client no longer starts an embedded Anywhere server; it reads the dedicated server's status and links instead.
- A tray icon opens settings, opens Radio Vault Anywhere or exits the server explicitly.
- Start with Windows writes a current-user sign-in entry and launches the server with `--background` and the authoritative database path.
- Remote native clients can be enabled in server settings, paired using a one-time six-digit code and revoked independently.
- Native Radio Vault has a Server connection settings page for discovery, pairing, certificate-pinned testing, reconnecting and forgetting a saved server.
- Tokens are unique to each client and never replace the separate Radio Vault Anywhere private-link credential.

## Acceptance

1. Start `RadioVault.Server.exe`, enable Server, Secure HTTPS access, Allow remote native clients and Start with Windows, then save.
2. Close the settings window. Confirm the server remains in the Windows tray and Radio Vault Anywhere still opens.
3. Launch `RadioVault.Server.exe` again and confirm it reopens the existing settings window instead of starting a second server.
4. Create a pairing code in server settings.
5. On another computer running the matching native client, open Settings > Server connection and choose Find servers.
6. Select the server, enter the six-digit code and pair. Confirm the server lists that client under Trusted clients.
7. Use Test and Reconnect in the native client and confirm the connection reports the server's broadcast and show counts.
8. Revoke that client on the server and confirm its next Test fails; pair it again, then use Forget in the client.
9. Sign out and back in to Windows, or run the saved startup command, and confirm the server starts without showing its settings window.
10. Use Exit Radio Vault Server from the tray and confirm Radio Vault Anywhere becomes unavailable.

Alpha 10 deliberately does not switch the native Library or playback pipeline to the remote server. That activation is Alpha 11, after this trust, lifecycle and revocation foundation is accepted.
