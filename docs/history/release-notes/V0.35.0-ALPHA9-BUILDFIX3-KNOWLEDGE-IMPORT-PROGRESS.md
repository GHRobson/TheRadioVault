# Radio Vault 0.35.0 Alpha 9 Buildfix 3 acceptance

This build preserves the Alpha 7 through Alpha 9 application and adds a scalable Knowledge Database transfer path.

## Acceptance checks

- Import `RadioVault-Archive-Knowledge-OA-RBI-RonRon-enriched.trvknowledge` from the Client, native Server settings and Radio Vault Web.
- Confirm preview reports 8,906 records: 8,506 matched, 384 missing and 16 requiring review.
- Confirm the progress bar advances by percentage and displays processed and total records.
- Close the importing window or disconnect the paired Client, reopen it and confirm the Server-owned job remains available and completes.
- Cancel a test import and confirm no partial changes are retained.
- Confirm a successful Server import creates and verifies a restorable database backup before changing the archive.
- Export from the Client, Server and Radio Vault Web and confirm all shows, transcripts and Explore content are present without choosing a show.
- Attempt to run an older installer over this build and confirm the installer refuses the downgrade.

## Reference benchmark

On 6 August 2026, a disposable library containing 8,404 matching broadcasts processed the 68.5 MB enriched package as follows: 1.4 seconds to decode, 2.7 seconds to preview, 32.1 seconds to transactionally import all 8,906 Research records, and 0.6 seconds to import 1,970 Explore pages. Total measured time including disposable-library setup was 37.9 seconds.
