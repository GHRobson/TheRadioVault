# Radio Vault 0.34.0 RC1 Buildfix 3 — server identity

Radio Vault Server now has a distinct but closely related application identity. Its yellow tile and broadcast/vault ring remain part of the main Radio Vault family, while the centre becomes a simple two-slot server tower designed to survive 16-pixel tray rendering.

The server variation is used by the server executable, tray icon, settings header, Windows shortcuts and server installer. Radio Vault Client and Radio Vault Web continue to use the approved main broadcast logo.

This release is visual only. It does not change the database, archive folders, pairing, certificates, Web access, playback, transcription, Research packs, models or caches.
