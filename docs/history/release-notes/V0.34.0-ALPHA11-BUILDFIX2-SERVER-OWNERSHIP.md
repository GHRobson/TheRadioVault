# Radio Vault v0.34.0 Alpha 11 Buildfix 2 — Clear server ownership

This buildfix makes the client/server relationship explicit in the native Settings screen.

- **Current server** shows the active server's name, address and whether it is on this computer or another computer.
- **Use this computer** is always visible. A client using the server on the same computer does not need Find Servers or pairing.
- **Server on another computer** is an optional, separate pairing area. Find Servers only searches the network for other server computers.
- **Radio Vault Anywhere** remains visible in the client as a convenient status and launch page, but is clearly labelled as hosted by the active Radio Vault Server.
- Closing Radio Vault Client does not stop Radio Vault Anywhere or the server.

## Acceptance

1. Start the matched Buildfix 2 server, then open the Buildfix 2 client on the same computer.
2. Open Settings > Server connection.
3. Confirm **Current server** says **Connected locally**, shows **This computer**, and displays the server address.
4. Confirm **Use this computer** is visible even when no remote server has ever been paired.
5. Confirm the remote section says Find Servers searches other computers and does not list the local server.
6. Open Settings > Radio Vault Anywhere.
7. Confirm the page identifies the hosting server, its location and address, and says the client does not host Anywhere.

Database schema 45, API v1 and capability generation 19 are unchanged.
