# Historical release notes

This directory preserves completed Radio Vault acceptance contracts, alpha notes, build-fix notes and earlier stable-release records.

These files remain part of the source package for auditability and regression-test context, but they are not the starting point for current development. Use the repository-root `README.md`, `BUILDING.md`, `DEVELOPMENT.md`, `MACOS-CLIENT.md` and `START-HERE-IOS-AGENT.md` files for active guidance.

The archive currently covers:

- legacy feature acceptance records;
- Radio Vault 0.32 release-candidate and final acceptance;
- Radio Vault 0.33 alpha and stable milestones;
- Radio Vault 0.34 alpha, release-candidate and stable milestones;
- Radio Vault 0.35 knowledge and Explore alpha milestones.

Keep future historical release records here instead of adding them to the repository root.
