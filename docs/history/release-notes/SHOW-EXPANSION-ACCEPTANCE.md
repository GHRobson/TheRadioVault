# Show Expansion Acceptance

Build and launch the package normally, then check:

1. **Research → Export pack** lists The Ron & Ron Show, Unmasked and Ron Bennington Interviews even before audio has been scanned for them.
2. A folder or filename clearly containing each canonical show name is classified into that show after a local Library scan.
3. Research packs whose manifest/broadcast `show` uses a supported alias or punctuation variant resolve to the canonical show during preview/import.
4. Exporting any of the new shows creates a `.trvpack` named for that show and optionally the selected year.
5. Existing Ron & Fez, Bennington and Opie & Anthony classification remains unchanged.

Radio Vault Anywhere and native desktop networking are not part of this acceptance pass.
