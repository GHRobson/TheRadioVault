# Radio Vault 0.35.0 Alpha 9 — Knowledge portability

Alpha 9 makes the archive-wide `.trvknowledge` database a safer interchange format for people, AI research agents and Radio Vault Server.

## Import acceptance

- A valid Alpha 6–8 Knowledge database remains importable.
- The server performs SQLite integrity and required-table checks before previewing data.
- Blank but otherwise valid citation titles receive a readable fallback.
- An incoming Explore page is matched to an existing page by stable GUID first and canonical slug second. A different AI-generated GUID no longer causes a unique-slug failure.
- Conflicting newer human revisions remain protected.
- Large local and paired-server operations receive a ten-minute bounded request window.
- The server creates and verifies a retained pre-import SQLite backup before changing the live archive.
- Import failures show a safe underlying reason and diagnostic reference instead of only a generic rejection.

## Export acceptance

- Export is archive-wide and includes every show and year, transcripts and the complete Explore snapshot.
- A failed export cannot destroy the previous destination file; Radio Vault builds and validates a temporary database before atomically replacing it.
- `PRAGMA quick_check` must return `ok` before the exported file is released.

## Documentation inside the database

Every newly exported database contains:

- `agent_instructions` — the concise starting instructions;
- `pack_documentation` — ordered Markdown covering goals, evidence practice, identities and the safe return checklist;
- `pack_schema` — a table-by-table purpose, stable identity and AI write policy;
- `pack_validation` — format, schema and export-time count guidance;
- `pack_change_log` — an append-only place for an AI agent to explain material changes, evidence limits and unresolved questions.

The AI agent must preserve stable archive identities, cite factual Explore claims, keep authoritative JSON and indexed columns consistent, validate image hashes and run `PRAGMA quick_check` before returning the same SQLite file with its `.trvknowledge` extension.
