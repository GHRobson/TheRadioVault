# Radio Vault v0.34.0 Alpha 8 - Anywhere native shell

Alpha 8 rebuilds Radio Vault Anywhere's navigation and application frame before the remaining native features are surfaced. The browser now follows the native app's sidebar, page-header and bottom-player structure on desktop, with a compact icon-first adaptation on phones.

## Acceptance

1. Replace both Alpha 7 applications with the matching Alpha 8 server and client, starting the server first.
2. Open Radio Vault Anywhere and refresh once. Confirm the desktop layout has a narrow left navigation rail, separate page header and full-width bottom player.
3. Confirm Dashboard, Search, Library, Favourites, Transcripts, Downloads, Queue and Archive Health still open their working destinations.
4. Expand Library and confirm the server's show list appears underneath it. Select a show and confirm the Library filters to it.
5. Open Search and confirm its controls appear in the page workspace rather than the navigation rail.
6. Confirm the bottom player supports back 15 seconds, play/pause or handoff, forward 30 seconds, seeking, information, playback speed and opening Now Playing.
7. On a phone, confirm the navigation becomes an icon strip, the selected destination remains clear and the compact player does not cover active controls.
8. Confirm Transcripts retains its teal identity and its library, individual jobs and batch tabs remain usable.
9. Confirm Moments, Research and Settings are visibly marked as future parity areas; Alpha 8 does not pretend those screens are complete.

The secure browser shell advances to cache v39 without deleting stored audio, artwork, progress or pending sync changes.

## Next roadmap slice

With the shell established, the next update can implement the native Research workspace and the remaining hidden feature destinations within this stable navigation structure.
