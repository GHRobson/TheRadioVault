# Radio Vault 0.35.0 Alpha 8

This release clarifies the knowledge architecture and removes several sources of accidental playback and interface clutter.

- Wiki is presented as Explore; Research is presented as Knowledge.
- Explore broadcast and Moment references open Broadcast Info without starting audio.
- Knowledge Database exports always contain the complete archive, every show, every year, transcripts and Explore content.
- AI-enriched imports tolerate blank citation titles by deriving readable titles from publisher, URL or archive identity.
- Now Playing uses the same collapsible transcript reader as Broadcast Info, has a corrected empty-queue state and sits at the bottom of navigation.
- Dashboard continuation panels remain stable in size and progress indicators stay within their cards.
- Missing artwork uses a lightweight line-art version of the Radio Vault mark.

The database schema remains 47 and the LAN capability generation remains 40.
