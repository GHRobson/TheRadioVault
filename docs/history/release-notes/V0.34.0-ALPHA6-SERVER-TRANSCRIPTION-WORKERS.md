# Radio Vault v0.34.0 Alpha 6 - Server-owned transcription workers

Alpha 6 moves the complete transcription execution lifecycle into RadioVault Server. Whisper, audio preparation, VAD, multi-speaker diarization, remembered voices, individual jobs and batch processors no longer depend on the native client remaining open.

## Acceptance

1. Start the matching Alpha 6 server. Its Transcription Service card should report Ready if the existing setup is available.
2. If setup is required, choose Install recommended transcription setup in the server settings window and allow it to finish.
3. Start the Alpha 6 native client and queue a five-minute sample.
4. Pause and resume the job, then allow it to complete.
5. Start another sample, close only the native client, wait briefly, reopen it and confirm the server-owned job continued.
6. Start a small batch and confirm pause, resume, reordering and cancellation work from the native Transcripts screen.
7. Confirm a speaker identity with remembered-voice training and verify the server processes the pending voice sample.
8. Confirm Research, Deep Research Packs, playback and native/Anywhere handoff still behave as in Alpha 5.

The Alpha 6 server and client are a matched pair. Keep RadioVault Server running while using either client.
