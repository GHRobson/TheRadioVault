# Radio Vault 0.33.0 Alpha 8 Buildfix 3

## Transcripts workspace redesign

The Transcripts page is organised around three distinct jobs:

- **Transcript review** contains saved broadcasts, transcript search, playback, exports, wording correction and speaker identification.
- **Transcription activity** contains individual job progress and the pause, resume, retry and cancel actions.
- **Batch runs** contains batch progress, queue order and batch-level controls.

The current-broadcast card keeps creation controls separate from saved-transcript review and explains that playback determines which broadcast a new job will use. The primary full-broadcast action appears first and changes to **Re-transcribe full broadcast** when appropriate.

## Layout corrections

- Every text action sizes to its full label.
- The 30-pixel `compact-action` style remains reserved for icon-only buttons and is not used in the Transcripts page.
- Export, phrase-review, individual-job and batch controls wrap as readable groups.
- Search navigation and speaker editing use separate rows so they do not compete for the same narrow horizontal strip.
- The transcript list and review workspace retain independent scrolling.

## Acceptance

- No Transcripts text button is clipped at the standard 1440×900 window size.
- The three workspaces have clear tab labels and do not compete for vertical space.
- Full transcription, samples, exports, review edits, speaker identity, individual job controls and batch controls remain available.
- All Buildfix 2 transcription continuity and safe replacement behaviour remains intact.
- The complete release gate passes without compiler warnings or errors.
