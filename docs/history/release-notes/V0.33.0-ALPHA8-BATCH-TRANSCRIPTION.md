# Radio Vault 0.33.0 Alpha 8 — Batch transcription

## Included

- Build a transcription batch for all shows, one show, one year or an exact date range.
- Preview matching broadcasts before starting.
- Skip broadcasts that already have transcripts.
- Use the saved Whisper, VAD and multi-speaker settings for every item.
- Reorder pending broadcasts with Higher and Lower controls.
- Track batch and individual-job progress together.
- Pause, resume or cancel the whole batch.
- Retry only failed broadcasts.
- Preserve completed transcripts when a batch is cancelled.
- Recover an active batch as Interrupted after Radio Vault restarts and resume its unfinished items.

## Acceptance checks

1. Open Transcripts, choose **New batch**, select a show and year, then choose **Preview**.
2. Confirm broadcasts with existing transcripts say they will be skipped and are not included in the ready count.
3. Start the batch and confirm the Batch runs panel shows the active item, aggregate percentage and completed/remaining counts.
4. Select a pending broadcast and move it Higher or Lower; confirm the saved order changes.
5. Pause the batch during an active transcription, wait briefly, then resume it.
6. Cancel a test batch and confirm completed transcripts remain available while pending items become Cancelled.
7. Retry a batch containing a failed item and confirm only failed broadcasts return to Pending.
8. Close Radio Vault during a disposable batch, reopen it, select the Interrupted batch and resume from the next unfinished broadcast.
