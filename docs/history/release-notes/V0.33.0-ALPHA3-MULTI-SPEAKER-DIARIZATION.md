# Radio Vault 0.33.0 Alpha 3 — Multi-Speaker Diarization

This build replaces the two-person TinyDiarize experiment with a separate local speaker-analysis stage. Radio Vault discovers the number of voices automatically and labels transcript turns as Speaker 1, Speaker 2, Speaker 3 and so on.

## Acceptance check

1. Open **Settings → Transcription** and select **Multi-speaker models only**, or use **Install recommended setup**.
2. Confirm the status says multi-speaker diarization is ready and leave **Identify and separate multiple speakers automatically** enabled.
3. Start with a five-minute sample containing at least three distinct voices.
4. Wait for both **Transcribing** and **Finding speakers** stages to finish.
5. Confirm the transcript contains separate anonymous speaker labels and that selecting a phrase still starts playback at the correct timestamp.
6. Retry with a longer broadcast only after the sample succeeds; speaker analysis is CPU- and memory-intensive.

All audio and model execution remain local. The model files download from the sherpa-onnx maintainer's published Hugging Face repositories and are verified against pinned SHA-256 digests before installation.
