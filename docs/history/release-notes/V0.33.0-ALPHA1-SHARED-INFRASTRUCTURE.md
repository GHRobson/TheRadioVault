# Radio Vault 0.33.0 Alpha 1 acceptance

This is a behaviour-neutral foundation build. It moves the final shared sources out of the retired WPF-era folder and into the dedicated `TheRadioVault.Infrastructure` project.

## What changed

- The old `TheRadioVault` shell directory is gone.
- Avalonia and the smoke tests reference `TheRadioVault.Infrastructure` normally instead of compiling linked copies of its source files.
- Database, Library scanning, Research Pack, preservation, backup and Radio Vault Anywhere infrastructure remains active with its existing namespaces and contracts.
- No database schema, Research Pack schema, playback rule or browser API changed.

## Quick acceptance

1. Start Radio Vault and confirm the Library and Dashboard load normally.
2. Play, pause and resume a local recording.
3. Open Research and confirm existing records and date-review queues load.
4. Open Settings, start Radio Vault Anywhere and confirm its browser page loads.
5. Run a Library scan only if you already have a safe test folder available.

Passing those checks confirms the project-boundary cleanup did not change visible behaviour. Transcription is the next feature phase.
