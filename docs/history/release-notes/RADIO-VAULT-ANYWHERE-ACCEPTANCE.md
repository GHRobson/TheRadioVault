# Radio Vault Anywhere restoration acceptance

1. Build and launch the Avalonia application.
2. Confirm local Library playback still starts, pauses, seeks and persists.
3. Open **Settings → Radio Vault Anywhere**.
4. Enable hosting, choose automatic startup if desired, and save.
5. Start Radio Vault Anywhere.
6. Open the private link on the PC browser and confirm the Library loads.
7. Open the same link on a phone or tablet connected to the same LAN.
8. Confirm browser playback starts, seeks and writes listening progress.
9. With HTTPS enabled, open secure setup and confirm the certificate/profile route is available.
10. Restart Radio Vault and confirm automatic hosting follows the saved setting.
11. Confirm there is no Connected Access page, desktop pairing code, LAN discovery, remote-client cache or handoff control.

Do not test native desktop client/server operation in this build.
