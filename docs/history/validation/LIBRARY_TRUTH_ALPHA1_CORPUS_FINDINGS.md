# Alpha1 desktop corpus findings

Source: `RadioVault-Library-Truth-GRAHAM-PC-2026-07-19-1258.trvtruth`

The report was generated by `0.28.0-alpha1-buildfix1` against the complete desktop archive.

## Report totals

- 7,169 physical files
- 7,091 current episode records
- 4,623 alpha1 canonical broadcasts
- 6,956 provisional recording variants
- 73 exact-duplicate groups
- 68 multipart broadcasts
- 295 proposed unknown dates
- 4,454 file-level review flags

## Root causes found

### False recording review

2,326 canonical broadcasts were marked **Needs attention** chiefly because they contained multiple non-identical recording families. This is normal archive structure. Alternate recordings now remain separate beneath one canonical broadcast without becoming review work.

### Date regression

291 of the 295 proposed unknown dates were already recoverable from the archive itself:

- 255 files used compact `RaFMMDD` names beneath `Ron & Fez 2003`.
- 35 files used indexed named-month dates such as `36 _1st Oct, 2009`.
- one file used an indexed short date: `41 _07_30_10`.

Only four files were genuinely unresolved.

### Incorrect future dates

Four source-indexed named-month files were parsed using the track number as the day and the real day as a two-digit year. Examples included:

- `27 March 16, 2010` → incorrectly 2016-03-27
- `12 June 26, 2009` → incorrectly 2026-06-12

Named-month parsing now requires the complete four-digit year.

### Multipart under-detection

Compact `P1`/`P2` and trailing `.1`, `-2`, or ` 2` segments were not consistently recognised. The report also confirmed that labels such as `take 2` must remain alternate-recording markers rather than parts.

### Headline pollution

3,389 files produced `Ron and Fez` as the proposed headline because underscore boundaries prevented the show alias from being removed. Semantic separator normalisation fixes this before headline extraction.

### AFRO semantics

The report assigned 19 files to the AFRO collection. Seven of those explicitly named Ron & Fez and should retain Ron & Fez as the parent collection, with AFRO represented as programme-format evidence. The 12 files in the dedicated AFRO folder remain AFRO when no parent show is known.

### Evidence rendering

Evidence and warning JSON used web-style camel-case names but was read using case-sensitive defaults, producing blank bullets in the exported report. Alpha2 reads it case-insensitively.

## Expected alpha2 direction

A corpus simulation of the corrected date and show rules yields:

- approximately 4 genuinely unknown dates
- approximately 4,330 canonical broadcasts before later slot/context refinements
- 12 dedicated AFRO collection files
- ordinary alternate recordings removed from manual review
- true exact-audio/conflicting-date cases preserved
