# Radio Vault historical records

This folder preserves immutable development and release evidence. These files
are useful when investigating why an old compatibility rule exists, but they
do not describe the current product plan.

- [`legacy-current`](legacy-current/) contains the 203 Alpha/Beta/RC validation
  and architecture records formerly kept in `docs/current`.
- [`release-notes`](release-notes/) contains versioned feature and acceptance
  notes.
- [`validation`](validation/) contains earlier Library Truth validation runs.
- Other versioned folders retain their original milestone evidence.

For active work, start with the [documentation index](../README.md).
