# Radio Vault v0.32.0 Alpha 3 acceptance checklist

## Build and startup

- [ ] Extract into a fresh folder and double-click `BUILD-AND-RUN.cmd`.
- [ ] NuGet restore, Release build and direct launch complete.
- [ ] The startup window appears, followed by the Avalonia shell.
- [ ] Existing library data opens without migration or re-adoption.

## Local playback

- [ ] Start a broadcast from Dashboard.
- [ ] Start a different broadcast from Library list and details.
- [ ] Play/pause, 15-second back and 30-second forward work.
- [ ] Drag the seek slider and confirm title/progress remain synchronized.
- [ ] Volume changes immediately.
- [ ] Repeated speed-button presses cycle from 0.5× through 3× and wrap.
- [ ] Artwork, show/date and status are correct.

## Persistence and completion

- [ ] Pause partway through a broadcast, close Radio Vault, reopen and resume near the saved position.
- [ ] Playback speed survives restart.
- [ ] Final progress is saved when closing while playing.
- [ ] Seeking near the end alone does not create completion evidence.
- [ ] Natural forward listening through the completion threshold marks the broadcast completed once.

## Multipart

- [ ] Start a known multipart broadcast.
- [ ] Part identity appears in Now Playing.
- [ ] Playback continues automatically into the next part.
- [ ] Seeking across a part boundary opens the correct physical file at the correct logical position.
- [ ] Resume position remains one logical position for the complete broadcast.

## Rubber-banding

- [ ] Dashboard, Library list and details all show restrained elastic overscroll at top and bottom edges.
- [ ] Normal wheel scrolling is unchanged away from an edge.
- [ ] Keyboard scrolling and focus navigation remain usable.
- [ ] A nested scroll area responds only when it is the nearest active viewer.
- [ ] Enabling Windows reduced-animation preference disables elastic displacement.

## Lifecycle

- [ ] Closing while idle leaves no process behind.
- [ ] Closing while playing flushes progress and leaves no process behind.
- [ ] The WPF reference still launches separately as `TheRadioVault.WpfReference.exe`.
