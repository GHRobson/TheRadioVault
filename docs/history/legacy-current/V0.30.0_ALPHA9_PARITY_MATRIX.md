# Radio Vault v0.30.0 Alpha 9 parity matrix

| Surface | Local library | Remote client | Expected Alpha 9 result |
|---|---|---|---|
| Dashboard / Continue Listening | Live | Live or cached | Same normal UI; server state when live |
| Library / filters / collections | Live | Live or cached | Same rows, counts, artwork and filtering |
| Global search / Explore | Broadcasts, people, topics, Research, Moments | Server broadcasts, Research, sources and Moments | Same navigation for available result types |
| Playback / multipart / progress | Local media | Server stream | Same controls and shared state |
| Queue / favourites / listened state | Local write | Server write | Same UI and server-backed result |
| Moments | Local read/write | Server read/write | Same normal workspace |
| Broadcast Info | Local details | Server details | Same identity, research, transcript status and artwork |
| Metadata Studio | Local write | Server write | Same editor; headline-review decisions stay server-owned |
| Research pack import/export | Local database | Server database with client file picker/save | Same preview/apply/export workflow |
| Research browse / sources / imports | Local database | Server read | Same normal workspace and filters |
| Research reconciliation / repair / rollback | Local maintenance | Server-owned | Explicitly unavailable remotely; never touches local database |
| Transcripts browse/view/search | Local repository | Server read | Same normal transcript UI |
| Transcript generation/import and advanced speaker editing | Local worker/storage | Server-owned | Explicitly performed on server |
| Settings — Archive | Local archive | Server snapshot | Shows the server archive and health |
| Settings — Playback | Local preference | Server-synchronised preference | Same values across clients |
| Settings — Connected Access | Host/client controls | Remote-client controls only | Contextual UI |
| Settings — Advanced | Available locally | Hidden | Deliberate local-maintenance boundary |
| Cache / reconnect | Not applicable | Remote-client feature | Cached read-only mode never opens local database |
| Parity diagnostics | Not applicable | Live server contract | All published surfaces available when connected |

Any mismatch outside the deliberate server-owned boundaries is an Alpha 9 defect.
