# v0.32.0 Alpha 12 Buildfix 4 Buildfix 2 — Static validation

## Scope

This is a focused runtime-stability correction over the successfully compiling Buildfix 4 Buildfix 1 source. It does not replace or weaken the transactional handoff coordinator.

## Root-cause checks

- Explicit local Play no longer assigns `_desiredPlaying` from a matching shared paused snapshot unless the operation is an intentional cross-device transfer preserving source state.
- `needsTransfer` requires a real active session owned by another device.
- `RefreshHandoffAsync` has a non-blocking single-flight semaphore and a one-second timer.
- Connected Access uses a shared certificate-pinned `SocketsHttpHandler` pool with bounded lifetime, idle timeout and connection count.
- Per-request `HttpClient` disposal uses `disposeHandler: false`, preserving the shared TLS pool.
- Committed Avalonia output passes through `EnsureTargetOutputStateAsync` before success is presented.
- Radio Vault Anywhere explicit gestures supply `desiredPlayingOverride = true`.
- Radio Vault Anywhere committed output passes through `ensurePhoneOutputState`.
- Phone player and change polling are separately single-flight.
- Phone page-exit reporting uses canonical logical position/duration and the current generation.
- Anywhere shell cache is v35.
