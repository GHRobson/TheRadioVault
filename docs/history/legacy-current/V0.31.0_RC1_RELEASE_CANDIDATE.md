# Radio Vault v0.31.0 RC1 — Core Hardening Release Candidate

Version: `0.31.0-rc1-core-hardening-release-candidate`

RC1 promotes the accepted Beta 1 WPF-independence proof without changing runtime behaviour. The user has confirmed the Windows solution build, complete release gate and live local/remote runtime acceptance. This candidate freezes that source for final packaging and stable-release qualification.

## Accepted baseline

- The Beta 1 source builds successfully on Windows.
- The complete source, architecture, WPF-independence, deterministic Release, regression-test and compiled ProductVersion gate passes.
- Existing local-library startup and playback work normally.
- Existing remote-client pairing, playback and progress write-through work normally.
- Repeated local/remote mode switching and orderly shutdown work normally.

## RC1 release engineering

- RC1 has one consistent identity across `VERSION.txt`, WPF assembly metadata, proof reports, validation, packaging and release documentation.
- The two Windows PowerShell 5.1 validator defects found during Beta 1 acceptance are integrated into the frozen validator.
- `RUN-RELEASE-GATE.cmd` provides a process-only execution-policy bypass without changing permanent PowerShell policy.
- The release gate requests deterministic compilation and verifies the ProductVersion embedded in the built WPF assembly.
- `package-release.ps1` creates a clean self-contained `win-x64` ZIP, `BUILD_INFO.json` and SHA-256 checksum.

## Compatibility boundary

- Database schema: **45**
- LAN capability generation: **14**
- API: **v1**
- Web-shell generation: **10**
- Anywhere shell cache: **v33**
- IndexedDB: **v2**
- Downloaded audio/artwork caches: **v1**

No migration, re-adoption, certificate replacement, re-pairing or cache reset is expected.

## Release-candidate rule

No new feature or architectural extraction enters RC1. Another candidate is justified only by a reproduced data-safety, privacy, build/package, shutdown, performance, accessibility or runtime release blocker. Otherwise the next build is `0.31.0` stable.
