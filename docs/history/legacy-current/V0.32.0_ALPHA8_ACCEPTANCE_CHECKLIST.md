# v0.32.0 Alpha 8 acceptance checklist

## Build and startup

- [ ] `BUILD-AND-RUN.cmd` restores, builds and launches the Avalonia `TheRadioVault.exe`.
- [ ] Existing local and Connected Access sessions open without migration.
- [ ] No startup failure log is produced during a normal launch.

## Shell and navigation

- [ ] Navigation labels are clear without persistent explanatory text.
- [ ] Tooltips provide the hidden descriptions.
- [ ] The connection-status control reports local/live/cached state and opens its actions.
- [ ] The persistent player keeps essential playback controls obvious and secondary actions discoverable.

## Search and progressive disclosure

- [ ] Library search updates after typing stops and never flashes stale results.
- [ ] Moments search updates after typing stops.
- [ ] Research search and filters update without an Apply button.
- [ ] Clear controls appear only when a filter/search is active.
- [ ] Technical broadcast identity is collapsed by default but remains complete.
- [ ] Research advanced metadata, Connected Access setup and advanced maintenance expand and collapse correctly.

## Workflow regression

- [ ] Dashboard, List/Grid Library and per-show navigation still work.
- [ ] Local and remote playback, seeking, speed, volume and multipart transitions still work.
- [ ] Favourites, Queue and Moments persist and write to the correct owner.
- [ ] Research and Metadata Studio retain local/remote write safeguards.
- [ ] Connected Access live, cached and reconnect behavior remains intact.
- [ ] Closing Radio Vault flushes final progress and leaves no process behind.

## Accessibility and feel

- [ ] Keyboard focus is clearly visible on buttons and navigation.
- [ ] Overflow menus and expanders can be operated by keyboard.
- [ ] Reduced-motion mode remains respected.
- [ ] No screen feels crowded with actions or technical labels that are not immediately relevant.
