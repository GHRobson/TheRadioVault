# Radio Vault v0.31.0 Alpha 3 — Windows/Platform Abstraction

Build identity: `0.31.0-alpha3-windows-platform-abstraction`

## Scope

Alpha 3 preserves the accepted Alpha 2 startup, mode-transition and shutdown behaviour while moving routine Windows integration behind platform-neutral Application contracts. It deliberately introduces no feature, schema, LAN protocol, cache or visual migration.

## New application ports

- `IExternalLauncherService` and `ExternalLaunchRequest` describe opening links, files, folders, text files, revealing an archive file and launching the current executable without exposing `ProcessStartInfo`.
- `ISystemAppearanceService` supplies the operating system's light/dark preference without exposing the Windows Registry.
- `IScreenBoundsService` and `WindowBounds` validate saved window placement without exposing WPF `SystemParameters`.
- `FileSelectionRequest` now carries file-existence and folder-creation policy while remaining platform neutral.

## Windows adapters

`TheRadioVault.Platform.Windows` now owns:

- shell/process launching;
- Windows theme preference lookup;
- WPF virtual-screen intersection checks;
- the existing dispatcher, notification, file-selection, clipboard and application-lifetime adapters.

The WPF composition root registers all of them through `WindowsApplicationServiceRegistration`.

## Live workflow cutover

Alpha 3 routes these existing behaviours through application ports:

- all clipboard operations, including web links, pairing codes, Research sources and remote parity diagnostics;
- opening Research source links;
- revealing an audio file in Explorer;
- opening the Radio Vault data folder, transcription models folder and crash log;
- relaunching after database reset;
- adding an archive folder;
- creating/restoring backups and importing/exporting metadata;
- choosing whisper.cpp executables, transcription models and VAD models;
- resolving the system theme and checking whether saved window bounds remain visible.

Specialised file dialogs and direct `MessageBox`/Dispatcher usage remain tracked work for Alpha 4.

## Architecture gate

`tools/Test-Architecture.ps1` now rejects direct `Process.Start`, WPF Clipboard, Windows Registry and `SystemParameters` use in the WPF project. The platform-neutral Application project still references only Core.
