# Radio Vault v0.30.0 RC1 static validation

Target: `0.30.0-rc1-multi-device-release-candidate`

## Verified in the source package

- Version identity is consistent across `VERSION.txt`, WPF project metadata, root documentation and the LAN discovery regression fixture.
- Database schema remains 45 and LAN capability generation remains 14.
- Alpha 9 parity, Research workspace, artwork, cache, synchronization and local-database isolation contracts remain present.
- Accepted Beta 1 incremental synchronization, deterministic full-reset conditions, copied sync diagnostics, safe mode transitions and bounded shutdown safeguards remain present.
- No new API route, capability generation, database migration, web-shell generation, IndexedDB version or audio/artwork cache identity is introduced.
- `release-gate.ps1` requests deterministic Release compilation, runs the regression/capability console suite and verifies the built application's ProductVersion against `VERSION.txt`.
- `build.ps1` publishes a clean self-contained `win-x64` output under `artifacts`.
- `package-release.ps1` records the release compatibility boundary, creates a ZIP and emits a SHA-256 checksum.
- RC1 release notes, release-candidate description and acceptance checklist are present.
- All 37 XAML/project XML files parse successfully, all 401 XAML event-handler references resolve to C# methods, and the 502-file source manifest, extracted-manifest hashes and ZIP integrity are checked during source packaging.

## Not verified in this environment

The packaging environment does not include the .NET 8 SDK, WindowsDesktop SDK, WPF runtime or the user's archive. It cannot prove:

- a real Visual Studio/Windows Release compilation;
- execution of the PowerShell release/package scripts;
- live HTTPS discovery, pairing and certificate pinning on the user's LAN;
- WPF responsiveness and media decoder behaviour with the full archive;
- existing-install upgrade behaviour;
- actual process disappearance and progress preservation across repeated Windows shutdown tests.

Those checks are covered by `V0.30.0_RC1_ACCEPTANCE_CHECKLIST.md`.
