# Radio Vault v0.31.0 Alpha 6 Buildfix 1 acceptance checklist

Target: `0.31.0-alpha6-di-tests-cleanup-buildfix1`

## Build gate

- [ ] Extract into a fresh folder.
- [ ] Build `TheRadioVault.sln` using **Release | Any CPU**.
- [ ] Run `validate-source.ps1`.
- [ ] Run `release-gate.ps1` and confirm the console regression suite passes.
- [ ] Confirm the compiled ProductVersion starts with the target identity.
- [ ] Confirm `diagnostic.log` contains `Application service graph validated` after launch.

## Local-library regression

- [ ] Start normally with the local library.
- [ ] Open, play, pause, seek and stop a broadcast.
- [ ] Change speed and volume.
- [ ] Test multipart transition and queue advancement.
- [ ] Confirm resume position, completion and listening history remain correct.
- [ ] Open common file/folder pickers and external links.
- [ ] Quit while idle and while playing; confirm the process exits.

## Remote-client regression

- [ ] Start against the saved server.
- [ ] Play, pause, seek and change speed remotely.
- [ ] Open Now Playing while connected and confirm show/date, headline, summary, hosts, guests, callers, mentioned people, topics, archive notes and artwork match Broadcast Info/server metadata.
- [ ] Change directly from one playing broadcast to another and confirm an older details/artwork response never replaces the current broadcast.
- [ ] Start from the encrypted cached Library with the server unavailable and confirm Now Playing still shows synchronized show/date, headline, summary, people/topics and cached artwork rather than blank cards.
- [ ] Stop and restart the server and confirm cached/read-only and reconnect behaviour.
- [ ] Trigger manual refresh repeatedly and confirm synchronization remains single-flight.
- [ ] Switch local → remote → local and leave each replacement window open longer than 12 seconds.
- [ ] Quit while synchronization is active and confirm the process exits.

## Compatibility

- [ ] Existing database opens with schema 45.
- [ ] Existing pairing remains valid.
- [ ] Existing encrypted client cache remains usable.
- [ ] No library adoption, migration or cache reset prompt appears.
