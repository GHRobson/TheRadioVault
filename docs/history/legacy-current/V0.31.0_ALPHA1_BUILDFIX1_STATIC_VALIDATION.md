# Radio Vault v0.31.0 Alpha 1 Buildfix 1 — static validation

Build identity: `0.31.0-alpha1-architecture-baseline-buildfix1`

## Corrected compile blocker

`WpfApplicationLifetime.cs` previously called `Application.Current.Shutdown(exitCode)` from inside the `TheRadioVault.Platform.Windows.Adapters` namespace. Because the solution now also contains the sibling namespace `TheRadioVault.Application`, the compiler resolved `Application` as that namespace and raised `CS0234`.

Buildfix 1 uses `global::System.Windows.Application.Current.Shutdown(exitCode)`, making the intended WPF type unambiguous. The missing `TheRadioVault.Platform.Windows.dll` diagnostic was only a cascade from that project failure.
