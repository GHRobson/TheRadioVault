# v0.32.0 Alpha 8 static validation boundary

The package is statically validated before handoff for:

- XML/XAML/AXAML/project parsing;
- JSON parsing;
- solution and project-reference integrity;
- Avalonia event-handler resolution;
- view-model binding/property coverage for the modified pages;
- progressive-disclosure markers for MenuFlyout and Expander usage;
- debounced Library, Moments and Research filtering;
- absence of direct SQLite access from Avalonia views and remote adapters;
- schema 45, LAN generation 14 and API v1 identity preservation;
- complete SHA-256 source manifest;
- ZIP integrity and Windows/OneDrive-safe internal paths.

Static validation cannot replace the Windows Avalonia compiler or live local/remote usability tests. Those remain explicit acceptance gates.
