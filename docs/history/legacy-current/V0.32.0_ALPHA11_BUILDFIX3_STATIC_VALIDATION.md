# Radio Vault v0.32.0 Alpha 11 Buildfix 3 — Static validation

Build identity: `0.32.0-alpha11-buildfix3-filename-parser-namespace-boundary`

This buildfix adds the missing platform-neutral `TheRadioVault.Core.Services` namespace to the Avalonia linked-service global-using boundary so `LibraryScannerService` can resolve `FilenameParserService`.

Validated statically:

- the Avalonia project retains its `TheRadioVault.Core` project reference;
- `FilenameParserService` remains public in `TheRadioVault.Core.Services`;
- the linked-service boundary imports Core models, Core services and legacy plain models only;
- no WPF or Windows-shell namespace is imported;
- Settings, Radio Vault Anywhere and playback compatibility sources are otherwise unchanged.

A Windows .NET build remains the definitive compilation and launch check.
