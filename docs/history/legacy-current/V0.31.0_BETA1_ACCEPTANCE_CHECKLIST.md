# Radio Vault v0.31.0 Beta 1 acceptance checklist

Target: `0.31.0-beta1-wpf-independence-proof`

## Build and proof

- [ ] Fresh extraction builds in **Release | Any CPU**.
- [ ] `validate-source.ps1` passes.
- [ ] `tools/Test-Architecture.ps1` passes with zero violations.
- [ ] `tools/Test-WpfIndependence.ps1` passes and reports `avaloniaHandoffReady: true`.
- [ ] `release-gate.ps1` passes all console regression tests and compiled ProductVersion verification.

## Local library regression

- [ ] Existing database opens without migration or re-adoption.
- [ ] Dashboard, Library, search, Research, transcripts, metadata, favourites, queue and Moments operate normally.
- [ ] Local playback, seeking, speed, volume, multipart transition, queue advancement and progress persistence operate normally.
- [ ] Quitting while idle and playing exits without a lingering process.

## Remote client regression

- [ ] Existing pairing opens without re-pairing or cache reset.
- [ ] Live startup, cached startup, server outage, automatic reconnect, manual reconnect and server restart operate normally.
- [ ] Playback and final progress write-through operate normally.
- [ ] Now Playing shows synchronized fallback details immediately and authoritative server details/artwork when live.
- [ ] Metadata, Research, search, transcripts, favourites, queue and Moments retain v0.30 parity and server-owned guards.

## Mode and soak

- [ ] Local → remote → local switching works repeatedly and replacement windows remain open beyond 12 seconds.
- [ ] Quitting during synchronization does not hang.
- [ ] At least one extended daily-driver session shows no stale state, duplicate writes or progressive slowdown.
- [ ] `diagnostic.log` contains the validated service-graph line and useful remote-session evidence.

A reproduced release blocker justifies a Buildfix or Beta 2. Otherwise proceed to v0.31 RC1.
