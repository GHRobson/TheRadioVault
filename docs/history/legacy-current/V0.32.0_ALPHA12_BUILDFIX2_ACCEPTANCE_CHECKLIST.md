- [ ] Open Dashboard and confirm the same broadcast appears as Featured Continue Listening with the same percentage as Now Playing.
- [ ] Leave playback running and confirm Dashboard and Library percentages never jump backwards.
- [ ] Test a multipart broadcast and confirm all views use the logical whole-broadcast position and duration.
- [ ] Complete a broadcast and confirm Dashboard/Library show exactly 100% and Continue Listening removes it.

- [ ] Navigate away from Dashboard and Library, return, and confirm current percentages are preserved.
