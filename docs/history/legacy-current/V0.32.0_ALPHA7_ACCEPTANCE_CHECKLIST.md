# v0.32.0 Alpha 7 acceptance checklist

## Build and startup

- [ ] `BUILD-AND-RUN.cmd` restores, builds and launches `TheRadioVault.exe`.
- [ ] Local and Connected Access startup modes still open correctly.
- [ ] No schema migration or Library re-adoption is requested.

## Library modes

- [ ] List mode renders existing rows, hover playback and selection correctly.
- [ ] Grid mode renders artwork cards, hover playback, favourite state and progress correctly.
- [ ] Switching List/Grid does not reset search, listening filter, selected show or current selection.
- [ ] Per-show views omit the redundant collection name from each item.
- [ ] All broadcasts retains collection names where they add context.
- [ ] The toolbar contains no redundant show or Canonical Library Truth pills.

## Compact and full broadcast information

- [ ] Selecting a broadcast loads summary, hosts, guests, callers, mentioned people and topics into the compact panel.
- [ ] The compact panel does not show canonical identity, collection or media structure.
- [ ] Right-click → Broadcast information opens the full information page.
- [ ] Full information shows canonical identity, broadcast UID, collection, media structure and detailed metadata.
- [ ] Back returns to the previous Library or Now Playing route.

## Now Playing

- [ ] The Now Playing sidebar entry opens the full playback page.
- [ ] Artwork, title, subtitle, multipart state and progress track the bottom player.
- [ ] Play/pause, ± skip, seek, speed, volume, favourite, Play next, Add to queue and Save Moment work.
- [ ] Summary, people, topics and notes load for local playback.
- [ ] The same information loads from the authoritative server in Connected Access mode.
- [ ] Full Broadcast information opens from Now Playing.

## Settings & Tools

- [ ] Local Library folders load.
- [ ] Add, enable/disable and remove registration work without deleting media.
- [ ] Archive-health analysis completes and reports a score and issue count.
- [ ] Application data and diagnostic log open normally.
- [ ] A remote client shows server ownership and does not expose local maintenance writes.

## Regression

- [ ] Accepted rubber-band scrolling remains responsive and jitter-free.
- [ ] Playback, progress persistence, multipart completion, favourites, Queue and Moments remain correct.
- [ ] Research, Metadata Studio, Connected Access cache/reconnect and remote writes remain correct.
- [ ] Shutdown flushes final progress and leaves no process behind.
