# Radio Vault v0.32.0 Alpha 10 Buildfix 8 — static validation

Build identity: `0.32.0-alpha10-buildfix8-library-view-refinement`

## Focused Library scope

- Dark theme surfaces use a restrained charcoal/slate hierarchy rather than the more visibly blue Buildfix 7 values; Radio Vault yellow remains unchanged.
- Main and child sidebar destinations use fixed widths and transparent selected states with a yellow border keyline.
- The standard Library list and archive day list are each hosted in a `library-list-frame` containing surface.
- Broadcast row columns are ordered play, favourite, date, title, listening progress and information. Play and information remain progressive-disclosure actions on hover or selection.
- The selected-broadcast panel exposes a direct full-information button and grouped pill collections for hosts, guests, callers and mentioned people.
- Year and month periods render through a square `WrapPanel` tile grid with optional artwork, show context, broadcast totals, listened percentage and favourite totals.
- Month drill-down returns to the same framed broadcast-list template and direct information action as the standard Library list.
- Buildfix 7 custom chrome and accepted Dashboard composition are unchanged.

## Checks performed

- All Avalonia AXAML and project XML files parse as XML.
- JSON documents parse successfully.
- XAML bindings introduced by this pass resolve to explicit presentation view-model properties.
- No WPF-only stroke properties or numeric `Auto` values were introduced.
- Source-manifest hashes are reproducible and the packaged ZIP is path-safe and CRC-clean.

A definitive Windows compile, launch and visual check remains required because this packaging environment does not provide the project’s .NET/Avalonia toolchain.
