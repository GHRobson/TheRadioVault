# v0.32.0 Alpha 12 Buildfix 4 Buildfix 2 — Acceptance checklist

Install the same build on the server and laptop. On the phone, fully close and reopen Radio Vault Anywhere, then accept the app-shell update/reload if shown so cache v35 is active.

## Connected Access stability

- [ ] Laptop starts in live server mode rather than cached mode.
- [ ] The Connected Access indicator remains live for at least ten minutes while Library and Dashboard are open.
- [ ] Opening several broadcasts and moving between Dashboard, Library and Now Playing does not turn the indicator orange.
- [ ] Manual Reconnect is not required during normal LAN use.
- [ ] A deliberate server shutdown changes the laptop to cached mode, and restarting the server returns it to live mode automatically.

## Ordinary playback

- [ ] With nothing playing anywhere, Play on the server starts audible output promptly.
- [ ] With nothing playing anywhere, Play on the laptop starts audible output promptly.
- [ ] With nothing playing anywhere, Play on the phone starts audible output promptly.
- [ ] Resuming a paused Continue Listening item plays rather than loading into a silent paused state.
- [ ] Play/Pause remains responsive after the initial media load.

## Transactional handoff

- [ ] Server → laptop produces audio on the laptop and stops the server only after target preparation.
- [ ] Laptop → server produces audio on the server.
- [ ] Server → phone produces audible phone output.
- [ ] Phone → server produces audible server output.
- [ ] Laptop → phone and phone → laptop both produce audible target output.
- [ ] Playhead position remains close across every move.
- [ ] A failed target preparation leaves source audio and durable progress unchanged.
- [ ] Rapid repeated taps do not create two outputs or competing transfers.

## Multipart and persistence

- [ ] A multipart broadcast moves correctly while positioned in a later part.
- [ ] Phone page close/reopen retains the canonical logical position rather than a part-local position.
- [ ] Closing and reopening the laptop retains the server-confirmed position.
- [ ] No failed or silent move resets progress to zero.
