# Alpha 12 Playback Baseline Recovery 1 — acceptance checklist

Do not test cross-device handoff in this build.

## Laptop first

- Build and launch successfully.
- Confirm the cached Library appears without waiting for a full server refresh.
- Start an ordinary broadcast and listen for at least one minute.
- Pause and resume.
- Seek backward by at least 30 seconds and confirm playback continues from the new position.
- Close Radio Vault, reopen it and confirm the position persisted.

## Server

- Install the same source build.
- Start a local broadcast and listen for at least one minute.
- Pause, resume, seek and relaunch; confirm local progress persists.

## Laptop after server restart

- Relaunch the laptop while its Library is still synchronising.
- Confirm cached browsing remains available.
- Start ordinary playback before the Library reports Live.
- Confirm audio plays and progress persists after another relaunch.
