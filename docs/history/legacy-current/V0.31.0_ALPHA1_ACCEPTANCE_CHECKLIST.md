# Radio Vault v0.31.0 Alpha 1 acceptance checklist

Target: `0.31.0-alpha1-architecture-baseline-buildfix1`

## Build and architecture gate

- [ ] Extract to a fresh short local path.
- [ ] Build `Release | Any CPU` in Visual Studio 2022/.NET 8.
- [ ] Run `validate-source.ps1`; source and architecture validation pass.
- [ ] Run `release-gate.ps1`; the full regression console suite passes and the compiled ProductVersion begins with `0.31.0-alpha1-architecture-baseline-buildfix1`.
- [ ] Confirm `artifacts/architecture/architecture-report.json` is created.

## Behaviour-preservation spot check

- [ ] Existing schema-45 library opens without migration or adoption prompts.
- [ ] Dashboard, Library, Search, playback, queue, favourites, Moments, Research and Transcripts behave as in v0.30.0.
- [ ] Server hosting and remote-client connection/parity remain available with capability generation 14.
- [ ] Local → remote → local switching remains safe.
- [ ] Quitting in local and remote mode completes normally and does not leave the process running.

## Boundary check

- [ ] `TheRadioVault.Application` and `TheRadioVault.Platform.Windows` appear in the solution and build.
- [ ] No existing user workflow or visual layout has unexpectedly changed.
- [ ] The architecture report contains zero violations and records the WPF coupling baseline.

Alpha 1 is accepted when the build/regression gate passes, the architecture report has zero violations, and ordinary local/remote use remains indistinguishable from accepted v0.30.0.
