# v0.32.0 Alpha 12 Buildfix 3 — Acceptance checklist

## Contextual control

- [ ] Start playback on the phone and confirm the laptop centre Play/Pause control changes to the arrow-into-desktop Move to this device glyph.
- [ ] Confirm no separate Continue on this device button appears on the bottom player or Now Playing page.
- [ ] Click the move glyph and confirm it immediately changes into the local Pause glyph when takeover succeeds.
- [ ] Repeat desktop server → laptop, laptop → desktop, phone → desktop and both reverse directions.
- [ ] Confirm a failed/disconnected claim returns to the move glyph and shows a useful error.

## Opening and transport

- [ ] Start a remote broadcast on the laptop and confirm the centre control never remains greyed out for the previous 10-second opening window.
- [ ] Press Pause while the source is still opening and confirm it opens paused.
- [ ] Press Play again before opening completes and confirm the latest intent wins.
- [ ] Confirm skip, seek, stop and speed remain disabled until this endpoint owns playback.

## Playhead alignment

- [ ] Leave phone and laptop visible while one plays and confirm their displayed positions normally remain within about one second on a healthy LAN.
- [ ] Repeat with the desktop server visible.
- [ ] Move a playing broadcast and confirm the new endpoint begins from the latest projected position, without a full-heartbeat backwards jump.
- [ ] Move a paused broadcast and confirm it remains paused at the same position.
- [ ] Test 0.5×, 1×, 1.5× and 2× speed and confirm projection follows the selected rate.
- [ ] Test a multipart broadcast across a segment boundary.
- [ ] Disconnect an owning device and confirm stale projection stops rather than advancing indefinitely.

## Regression

- [ ] Close and reopen the remote client and confirm server-saved progress persists.
- [ ] Confirm Dashboard and Library percentages match Now Playing on all endpoints.
- [ ] Confirm remote Archive Health, manual scan, folder watcher and hourly scan still work.
- [ ] Confirm Alpha 12 Undated and Coverage Research views still load and edit correctly.
