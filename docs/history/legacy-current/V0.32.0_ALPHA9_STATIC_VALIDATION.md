# v0.32.0 Alpha 9 static validation boundary

The package is statically checked for XML/AXAML/project and JSON parsing, solution/project references, Avalonia event-handler resolution, modified view-model binding coverage, archive hierarchy service boundaries, navigation-route placement, Dashboard limits and carousel markers, absence of remote SQLite fallback, schema/LAN/API identity preservation, complete SHA-256 source manifest, ZIP integrity and Windows/OneDrive-safe paths.

Buildfix 1 additionally verifies that Dashboard visual-tree attach/detach handlers use `global::Avalonia.VisualTreeAttachmentEventArgs` and do not import the type from `Avalonia.VisualTree`.

Static checks cannot replace the Windows Avalonia compiler, live local/remote playback, visual review, timer behaviour or actual listened-percentage verification against the user's library. Those remain explicit acceptance gates.
