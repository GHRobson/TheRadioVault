# Radio Vault v0.30.0 Final Acceptance Checklist

Use the authoritative server library and a Windows remote client that already passed RC1. Preserve the accepted RC1 application package and a known-good database backup until this pass is complete.

## 1. Build and package

- [ ] Extract the stable source to a fresh short path and build the full solution in Release.
- [ ] Run `release-gate.ps1`; validation, compilation, regression/capability tests and assembly-version verification pass.
- [ ] Run `package-release.ps1`; a self-contained `RadioVault-0.30.0-win-x64.zip`, `BUILD_INFO.json` and checksum are produced.
- [ ] Extract the generated binary ZIP into a clean folder and launch it successfully.
- [ ] About/diagnostics, server discovery, copied parity diagnostics and `BUILD_INFO.json` report `0.30.0`.

## 2. Existing-install promotion

- [ ] Launch v0.30.0 over the accepted RC1 application/data locations on the server.
- [ ] Database schema remains 45 and canonical library counts are unchanged before any new scan.
- [ ] Library folders, settings, certificate, paired clients, playback state, favourites, queue, Moments, transcripts and Research remain present.
- [ ] Upgrade the remote client without clearing its cache or pairing information.
- [ ] The saved server reconnects normally with no re-pairing, certificate replacement or cache reset request.

## 3. Final regression spot-check

- [ ] Refresh **Remote-client parity**; every published surface reports available.
- [ ] Play and seek within one single-file and one multipart broadcast remotely.
- [ ] Verify progress, favourite, listening status and queue mutations reach the server once.
- [ ] Make one remote Metadata Studio edit and open one Research result from global search.
- [ ] Stop the server while browsing; cached/read-only mode remains usable and mutations are blocked clearly.
- [ ] Restart the server; the client reconnects automatically and live state replaces cached state.
- [ ] Switch local library → paired server → local library, leaving each replacement window open beyond 12 seconds.
- [ ] Quit once while idle locally, once during remote playback and once while disconnected; each process disappears within 12 seconds and the next launch is clean.

## Acceptance rule

v0.30.0 is accepted when the final metadata promotion builds and packages cleanly, existing RC1 data and pairing state open directly, all spot-checks pass, and no regression, data loss, duplicate mutation, stale-cache lockout, false mode-switch shutdown or indefinite process hang is observed.
