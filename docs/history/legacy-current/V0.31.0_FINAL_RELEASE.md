# Radio Vault v0.31.0 — Core Hardening

Version: `0.31.0`

## Release boundary

v0.31.0 is a release-identity and documentation promotion of the successfully built, fully release-gated and runtime-accepted RC1 implementation. It introduces no new feature behaviour, database migration, API route, LAN capability, pairing requirement or cache identity.

The release completes the pre-1.0 Core Hardening milestone. Radio Vault now has explicit, executable boundaries around startup and shutdown, application composition, Windows platform services, playback, listening-progress policy, completion evidence and authoritative remote Library synchronisation. The current WPF application remains the shipping desktop UI while the reusable backend is ready for the planned Avalonia shell.

## Completed capabilities

- Platform-neutral application contracts and a deliberate Windows adapter project.
- Validated and frozen service composition before the first window opens.
- Application-owned startup selection, ordered shutdown and duplicate-safe mode transitions.
- Application-owned playback sessions, protected progress persistence and natural-completion evidence.
- Replaceable local media-engine creation behind `ILocalPlaybackEngineFactory`.
- Shared authoritative remote-session synchronisation with cancellation, timeout, retry and cache/live state.
- Remote Now Playing details loaded from the authoritative server rather than the client cache database.
- Executable architecture and WPF-independence gates with machine-readable reports.
- A defined Avalonia handoff that separates reusable seams from deliberate presentation replacement.

## Compatibility

- Database schema: **45**.
- LAN capability generation: **14**.
- API: **v1**.
- Web-shell generation: **10**.
- Anywhere shell cache: **radio-vault-anywhere-shell-v33**.
- IndexedDB: **v2**.
- Downloaded audio and artwork caches: **v1**.

Existing RC1, Beta 1 and v0.30 data opens directly. No re-adoption, database migration, cache reset, certificate replacement or re-pairing is expected.

## Next milestone

After stable acceptance, development moves to v0.32 Alpha 1: a new Avalonia desktop project and shell built against these frozen application boundaries while the WPF application remains the working reference.
