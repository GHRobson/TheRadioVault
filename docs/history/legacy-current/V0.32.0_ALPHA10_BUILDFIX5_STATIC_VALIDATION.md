# Radio Vault v0.32.0 Alpha 10 Buildfix 5 — static validation

Build identity: `0.32.0-alpha10-buildfix5-authoritative-audit-scope-fix`

## Compile correction

- The per-record authoritative-audit flag is named `recordIsAuthoritativeAudit`.
- The post-loop import-summary flag is named `containsAuthoritativeAudit`.
- `ApplyImportAsync` no longer declares `authoritativeAudit` in a nested loop and again in its enclosing method scope, removing the reported `CS0136`.
- The original authoritative replacement, manual-field override, conflict retirement and summary behaviour is otherwise unchanged.
