# Radio Vault v0.32.0 Alpha 8 — UX Audit & Progressive Disclosure

## Purpose

Alpha 8 deliberately pauses feature migration to review the existing Avalonia application as a complete user experience. The goal is not to remove capability; it is to expose capability at the moment it becomes useful.

The audit uses five questions for every screen:

1. What is the user trying to do here?
2. Which action or information must be visible now?
3. Which secondary actions can wait for hover, selection, a menu or an expander?
4. What feedback confirms progress, success or failure?
5. Can the journey be completed comfortably with mouse, keyboard and reduced motion?

## Applied audit

### Application shell

- Shorter navigation labels with descriptions moved to tooltips.
- Removed persistent version and explanatory navigation text.
- Consolidated server/local state into one connection-status control with contextual actions.
- Simplified the persistent player: transport remains visible; Queue, Moment and full-page actions move to overflow.

### Dashboard

- Reduced duplicate status labels and metrics.
- Retained the archive overview and listening progress as the visual focus.
- Moved secondary broadcast actions into row overflow menus.

### Library

- Search now updates after a short pause rather than requiring an Apply/Search action.
- Clear appears only when search or listening filters are active.
- Primary playback remains immediately available; favourite, Queue and full-information actions remain contextual.
- Compact broadcast details use straightforward summary, people and topic sections instead of nested technical cards.

### Now Playing and broadcast information

- Now Playing prioritises artwork, title, progress and transport.
- Save Moment, Queue and full-information actions move to overflow.
- Full Broadcast information presents human-readable summary, people, topics and notes first.
- Canonical identity, collection and media structure remain available in a collapsed Technical archive details section.

### Queue and Moments

- Queue prioritises Play first and direct item playback; ordering/removal actions remain in contextual menus.
- Moments prioritises Save current position, Jump and Save; deletion remains contextual.
- Moment search updates while typing.

### Research and Metadata Studio

- Reduced five overview cards to three high-value signals.
- Search updates while typing.
- Show/status/review filters live behind a Filters expander.
- Common metadata remains visible; station/type/variant/era/confidence/review controls live behind Advanced metadata.
- Save remains the primary action; review/revert actions move to overflow.

### Connected Access and Settings & Tools

- Current connection state is presented first.
- Pairing and startup-Library selection are disclosed only when needed.
- Reconnect remains primary; testing and forgetting a server are contextual.
- Common Library-folder actions remain visible, while advanced maintenance remains collapsed.

## Boundaries

This build does not change database ownership, LAN capability negotiation, API routes, encryption, playback semantics or Research write safeguards. Advanced destructive/long-running maintenance remains in the WPF reference until its cancellation, backup and recovery behavior reaches parity.
