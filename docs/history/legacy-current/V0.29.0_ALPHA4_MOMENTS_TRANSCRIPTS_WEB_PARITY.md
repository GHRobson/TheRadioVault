# Radio Vault v0.29.0 Alpha 4 — Moments, Transcripts & Web Feature Parity

Version: `0.29.0-alpha4-moments-transcripts-web-parity`

Alpha 4 extends the Anywhere application-service contract beyond playback and library browsing.

## Delivered

- `GET /api/v1/broadcasts/{id}/transcript` returns the preferred timed transcript for the canonical broadcast.
- Transcript segments include timing, speaker, content kind, review state and confidence without exposing physical paths.
- Broadcast Info lazily loads transcripts and allows tap-to-seek on the canonical timeline.
- `POST /api/v1/broadcasts/{id}/moments` creates an idempotent canonical Moment from the phone.
- A versioned delete contract is present for Moment management.
- Server capabilities now advertise transcript read access and Moment write access.
- Alpha 3 offline state, sync icons and compact Library filtering remain unchanged.

## Compatibility

- Database schema: 45
- Capability generation: 4
- Secure shell cache: v29
- Audio/artwork download caches: v1
