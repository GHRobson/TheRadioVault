# Radio Vault v0.29.0 — Radio Vault Anywhere

Version: `0.29.0`

## Release boundary

v0.29.0 is a metadata-only promotion of the accepted RC1 implementation. It adds no new feature behaviour, API contract or database migration. The secure application-shell cache advances from `radio-vault-anywhere-shell-v32` to `radio-vault-anywhere-shell-v33` so installed phones replace release-candidate HTML while retaining device media, offline state and pending synchronisation work.

## Completed Anywhere capabilities

- One Radio Vault server exposes versioned application services and a bounded bootstrap snapshot.
- Responsive phone, tablet and desktop web layouts share the canonical Broadcast identity used by the server application.
- Library browsing supports server-side show, year, month, exact-date and listening-status facets, compact mobile filters and bounded 80-broadcast pagination.
- Canonical multipart playback, seeking, resume state, favourites, queue and listening status remain consistent between desktop and web clients.
- Manual device downloads support offline playback, seeking and resume without introducing automatic downloads.
- A durable IndexedDB mutation journal replays offline progress and state changes after reconnect, using stable mutation identifiers, deduplication, retry backoff and visible blocked-change recovery.
- Download auditing, cache reconstruction and Needs Repair records protect locally stored broadcasts.
- Broadcast Info supports canonical Moments and timed transcripts with speaker labels and tap-to-seek timestamps.
- Compact accessible synchronisation icons keep the iPhone interface clear while a detailed status sheet exposes pending and blocked changes.
- Privacy-safe diagnostics can be copied or exported without archive titles, filenames, paths, tokens or content.
- App-shell update and repair controls preserve downloaded audio, artwork, IndexedDB listening state and pending synchronisation changes.
- Keyboard focus, skip navigation, dialog semantics, Escape-key dismissal and reduced-motion handling complete the web accessibility pass.

## Compatibility

- Database schema remains 45; existing v0.28, Alpha, Beta and RC1 schema-45 databases open directly.
- Capability generation remains 7 and desktop web-shell generation remains 10.
- IndexedDB remains version 2.
- Downloaded audio and artwork caches remain `radio-vault-anywhere-audio-v1` and `radio-vault-anywhere-artwork-v1`.
- Audio files and canonical archive rows are not renamed, moved or rewritten by the final promotion.

## Release acceptance

Build the final package in Release configuration, run `release-gate.ps1`, then complete `V0.29.0_FINAL_ACCEPTANCE_CHECKLIST.md`. Retain a known-good database backup and the RC1 source until normal desktop/iPhone use confirms the final shell has replaced RC1 cleanly.
