# v0.32.0 Alpha 9 acceptance checklist

## Build and startup

- [ ] `BUILD-AND-RUN.cmd` restores, builds and launches Avalonia.
- [ ] Existing local and Connected Access sessions open without migration.
- [ ] No normal-startup failure log is created.

## Navigation and settings

- [ ] Connected Access appears in Settings and not as a sidebar destination.
- [ ] Queue is visible in Now Playing and not as a sidebar destination.
- [ ] Now Playing is the final sidebar item.
- [ ] Search and Favourites have dedicated sidebar destinations.
- [ ] Library still expands to the actual shows and counts in the archive.

## Library hierarchy

- [ ] Grid mode starts with years.
- [ ] Selecting a year shows months.
- [ ] Selecting a month shows broadcasts as a list.
- [ ] Year and month cards show correct broadcast counts and listened percentages.
- [ ] Back/root navigation works in All broadcasts and individual shows.
- [ ] Search and listening collections switch cleanly to direct List results.

## Dashboard

- [ ] The latest unfinished broadcast is featured separately.
- [ ] Four additional unfinished broadcasts appear below it.
- [ ] Recently added never displays more than five broadcasts.
- [ ] Surprise me starts an available broadcast.
- [ ] On this day shows one card at a time, advances automatically and responds to previous/next controls.

## Regression and accessibility

- [ ] Local and remote playback, Queue continuation, favourites and Moments persist correctly.
- [ ] Research and Metadata Studio retain ownership safeguards.
- [ ] Keyboard focus, reduced motion and responsive elastic scrolling remain correct.
- [ ] Closing Radio Vault flushes final progress and leaves no process behind.
