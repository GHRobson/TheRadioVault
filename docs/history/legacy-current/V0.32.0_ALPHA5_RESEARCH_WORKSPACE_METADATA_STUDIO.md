# Radio Vault v0.32.0 Alpha 5 — Research Workspace & Metadata Studio

Build identity: `0.32.0-alpha5-research-workspace-metadata-studio`

Alpha 5 migrates the normal Research workspace into Avalonia through a new platform-neutral `IResearchWorkspaceService`. The service reads the existing schema-45 Research library, provides overview/filter/detail/source/import-history read models, and owns guarded local metadata writes.

Metadata Studio edits headline, summary, station, edition, variant, era, type, archive notes, confidence, people and topics. When a Research record is attached to a local archive episode, compatible metadata and artwork are also synchronized to that episode. Every manual field decision receives protected manual provenance.

The service rejects any update marked as remote-owned. A connected Avalonia client must eventually send those edits to the authoritative server rather than writing its local cache.

The WPF reference remains available for specialised Research reconciliation, rollback, import/export and repair workflows that are not part of this normal Alpha 5 workspace.
