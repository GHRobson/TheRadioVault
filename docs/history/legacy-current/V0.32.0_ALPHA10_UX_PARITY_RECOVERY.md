# Radio Vault v0.32.0 Alpha 10 — UX and parity recovery

Build identity: `0.32.0-alpha10-buildfix15-buildfix2-presentation-log-boundary`

Alpha 10 deliberately pauses feature expansion. Its release criterion is not that more controls exist; it is that established Radio Vault tasks are understandable, efficient and visually coherent in Avalonia.

## Visual identity

Radio Vault yellow is the primary accent for selection, active playback, focus, progress and the strongest calls to action. The surrounding surfaces stay restrained so the accent communicates meaning rather than becoming decoration. Settings exposes System, Light and Dark appearance modes.

## Content-first layout

The shell uses integrated Avalonia window chrome: the app label remains at the left, while Connected Access status and window controls share the right edge. The Dashboard heading scrolls with Dashboard content instead of reserving a permanent strip; other page headings remain fixed where they still aid orientation. Library and Research retain purposeful card, list-row and detail-pane frames. Density comes from tuned spacing and progressive disclosure rather than erasing the visual boundaries that make each screen readable.

## Dashboard

- The most recently used unfinished broadcast is the dominant next action.
- Four more unfinished broadcasts remain immediately accessible.
- Surprise Me sits with the main listening choices.
- Four compact statistics use distinct, uncircled vector icons for faster recognition.
- Recently Added is limited to five broadcasts.
- On This Day presents one card at a time, includes topics and uses timed, centred pagination dots.
- Playback progress shown in Dashboard rows follows the live playhead.

## Library

- List mode retains compact, readable two-line dates.
- Hearts replace stars throughout the application.
- The current broadcast stays highlighted while the user scrolls.
- Hover play/pause is positioned beside the date and favourite action.
- Listening bars are deliberately compact and remain clear of the scrollbar.
- Chronological mode remains year → month → broadcast list, with square year/month tiles, listened percentages, a left-aligned interactive breadcrumb and the full selected-broadcast panel retained at day level.

## Research and Metadata Studio

The master list and editor receive the majority of available space. Search and common filters remain compact; advanced metadata and diagnostics are disclosed when needed. Import and export are restored behind a platform-neutral service boundary. Local import creates a normal SQLite backup first and normally preserves manually modified research fields; remote import/export always executes on the authoritative server. Packs carrying the explicit `authoritative_audit` policy instead replace or clear audited research-owned fields while leaving ambiguous identities and all media/listening/personal state untouched.

## Playback continuity

Playback ownership is represented as one server-owned session rather than independent device playheads. The active device is visible in Avalonia Now Playing and the persistent player. When another device owns the session, Continue on this device claims the current broadcast, position and speed before opening local audio. The previous endpoint is paused by the server ownership transition.

Volume and output-device choices remain local. Broadcast identity, logical multipart position, speed, queue context and ownership remain shared.

## Deliberate boundary

In Alpha 10 the authoritative server application remains the retained WPF reference shell. The Avalonia remote client and the existing iPhone/web client participate in the same server session. Migrating the server-hosting controls themselves into Avalonia remains a separately guarded parity task; this build does not silently create a second server or a second database writer.


## Buildfix 8 Library refinement

The Library now uses a framed list surface, progressive row actions in the requested order, direct broadcast-information controls, pill-based people presentation and a genuine square-tile year/month browse grid. Sidebar selection is a fixed-width yellow keyline and dark surfaces are less blue.

## Buildfix 9 Library navigation correction

Sidebar selection no longer relies on the Fluent ToggleButton checked surface: fixed-width main and child navigation Borders own the transparent yellow keyline directly. Chronological Library browsing now presents a left-aligned All → year → month breadcrumb whose earlier levels are direct navigation actions, and month/day broadcast lists reuse the same complete selected-broadcast information panel as ordinary list mode.
