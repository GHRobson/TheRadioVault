# Radio Vault 0.35.0 Alpha 1 — Wiki foundation

This alpha begins the built-in Radio Vault Wiki. The dedicated Server remains the sole owner of the database; the native Client provides the first complete editing surface.

## Included

- Human-editable pages for shows, people, organisations, events, places and topics.
- Stable page IDs, slugs, aliases, draft/published/archive state, revision history and optimistic concurrency protection.
- Structured sources and Wikipedia-style numbered citations.
- Images stored with checksum, creator, copyright, licence, source, caption, alt text and point-in-time or representative date ranges.
- Show timelines ordered through the years, with dated events that can cite sources, use images and point to relevant broadcasts or Moments.
- `.rvwiki` export containing readable Markdown plus structured JSON and image files for an external AI agent.
- Preview-before-import with checksums, conflict reporting and protection for newer human edits.

## Acceptance

1. Upgrade the existing Server and Client. Confirm the archive opens normally and Connected Access reports schema 46 and capability generation 37.
2. Open **Wiki** in the Client. Create a draft page, add an alias, edit its Markdown, save it, edit it again and confirm its revision increases.
3. Export a Wiki authoring pack. Confirm the selected `.rvwiki` file is created.
4. Open the pack as a ZIP and confirm it contains `AUTHORING.md`, `manifest.json`, `pages/index.json`, a Markdown file for each page, citation/source JSON, timeline JSON and image files when present.
5. Import the unmodified pack. Confirm Radio Vault shows a preview before the final import action.
6. Add a cited page, a properly licensed dated image and a timeline event in a copy of the pack, then preview and import it. Confirm the page, numbered citation, image metadata and timeline event appear in the Client.
7. Change a page in Radio Vault after exporting, change the same page in the old pack, then import. Confirm the newer human revision is reported as a conflict and is not overwritten.
8. Re-run Library playback, native/Web handoff, transcription controls and Deep Research Pack preview/import to confirm the schema addition did not regress 0.34 behaviour.

## Not yet included

This first slice does not yet expose Wiki browsing/editing in Radio Vault Web, provide an in-app visual timeline editor or generate the baseline content itself. Those build on this exchange and data foundation in subsequent 0.35 alphas.
