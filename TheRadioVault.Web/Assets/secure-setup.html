Secure offline access

This one-time setup lets Safari trust Radio Vault's private HTTPS server. Afterwards, downloaded broadcasts can open from a cold offline launch when the computer is unreachable.

1 · Install the profile

Tap below, allow the profile download, then open Settings → Profile Downloaded and install Radio Vault Secure Offline Access.

Download iPhone profile Download certificate only
2 · Enable full trust

Open Settings → General → About → Certificate Trust Settings, then enable full trust for Radio Vault Local Root CA.

The root private key remains on the Radio Vault computer. The phone receives only the public certificate used to verify this local server.
3 · Test secure access

Return here and tap the button below. Once Radio Vault opens over HTTPS, Safari will install its offline application shell automatically.
