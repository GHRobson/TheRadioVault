# Radio Vault 0.34 Alpha 20 — release hardening

Alpha 20 is a feature-frozen reliability release. It keeps the working Alpha 19 playback and iPhone broadcast-switch path intact while auditing the shared client/server contract, cache-first startup, transcription ownership, Library and Research paths, and Windows packaging.

## Changes in this build

- Client version text now comes from the application assembly everywhere it is presented instead of a handwritten release label.
- Deep Research packs record the same application version as the installed client.
- Advanced Settings shows the capability generation actually negotiated with the selected server.
- Settings consistently explains that transcription models and processing belong to the active server.
- Obsolete Radio Vault Anywhere and pre-server placeholder wording has been removed from the visible compatibility and local-connection status.
- Client and server installer scripts now rebuild their release payload unconditionally before compiling the installer and fail if the expected executable was not produced.
- The connected contract advances to generation 31 and the Radio Vault Web shell cache advances to v55.

## Acceptance pass

1. Upgrade Radio Vault Server on the library computer, then upgrade Radio Vault Client.
2. Confirm the server starts in the background, the client reconnects to the saved server and the splash describes the real connection and cache state.
3. Open Dashboard, Search, Library, Transcripts, Research and Settings. Confirm cached views appear quickly and subsequently refresh without losing server connection state.
4. Play a broadcast in the client, move it to Radio Vault Web on a phone, change to another broadcast, then move playback back to the client.
5. Start a five-minute transcription sample, exercise pause, resume and cancel, and retry a completed or failed broadcast from its context menu.
6. Export a Deep Research pack for a broadcast with a transcript and confirm the transcript and Alpha 20 application version are included.
7. Add or rescan a Library folder on the server and confirm new shows and broadcasts appear in the client after refresh.
8. In client Settings, confirm the displayed version matches `0.34.0-alpha20` and compatibility is described as negotiated with the active server.

Alpha 20 is ready to promote toward beta only after this pass completes on the main library computer, a remote Windows client and the iPhone web client.
