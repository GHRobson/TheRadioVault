# Radio Vault v0.34.0 Alpha 12 — Server ownership completion

Alpha 12 makes the dedicated server the single owner of the archive and transcription installation for every native client, even when client and server are on the same computer.

## What changed

- The client no longer opens a local Radio Vault database or creates local archive backups.
- Archive folders, Archive Health and Library scans always come from the active server.
- Transcription status, settings and recommended installation always come from the active server.
- Client-side transcription and remembered-voice engines are replaced by server-bound controls.
- Server settings use clear running, insecure and stopped colours.
- Start and Stop are mutually exclusive; irrelevant controls are hidden.
- Transcription setup and cancellation are only shown when applicable.
- Transcription teal is reserved for the sidebar identity icon.
- Scrollbars auto-hide until the interface is being scrolled.

## Acceptance

1. Start the Alpha 12 server and client on the same computer.
2. Confirm Library, Dashboard, Search, playback, transcripts and research still work.
3. In client Settings > Archive, confirm the page identifies the server-owned archive and can run a scan.
4. In client Settings > Transcription, confirm the active server's setup is shown and server paths are clearly labelled.
5. Confirm the Transcripts sidebar icon remains teal while the page uses the standard yellow and neutral palette.
6. In server settings, confirm running status is green, insecure HTTP is amber and stopped status is red.
7. Confirm Start is hidden while running, Stop is hidden while stopped, and transcription setup buttons only appear when useful.
8. Confirm scrollbars fade away when no scrolling is taking place.

Database schema 45, API v1 and capability generation 19 are unchanged.
