# Radio Vault 0.34.0 stable

Radio Vault 0.34 completes the dedicated-server architecture. Radio Vault Server is the authority for the Library, database, media, listening state, Research records, transcripts and background transcription jobs. Radio Vault Client and Radio Vault Web are clients of that server, including when they run on the same computer.

## Stable release contract

- The Server is a background application with a settings-only interface.
- The native Client retains the full desktop workspace and uses a persistent encrypted response cache for fast startup and temporary server outages.
- Radio Vault Web provides the native-style Dashboard, Search, Library, playback, downloads, transcripts, Research and settings surfaces on phones and browsers.
- Playback ownership and transactional handoff are shared across native and Web devices. The source keeps ownership unless the target decoder is ready and aligned.
- Transcription models, processing, jobs and durable transcripts remain on the Server.
- Deep Research Packs include transcript text, timings and speaker labels and can be previewed before import.
- Client and Server installers preserve database files, folders, models, transcripts, certificates, pairing trust, settings and encrypted caches during upgrades.
- Radio Vault Web remains a private LAN service in 0.34. Internet-facing remote access is deliberately deferred to a separately hardened later release.

## Accepted verification

- Upgrade preservation across the RC installer line.
- Repeated native-to-iPhone and iPhone-to-native handoff across multiple broadcasts.
- Sustained iPhone playback without periodic forward or backward corrections.
- Client cache-first startup, server restart recovery and bounded live refresh.
- Library folder management, listening actions, transcription job controls, Research-pack import/export and native/Web downloads.
- NuGet direct and transitive dependency audit with no known vulnerable packages after the SQLite security rollup.
- Deterministic Release builds, source validation and the complete automated smoke suite.
