# Radio Vault 0.33.0 stable

## Release scope

Radio Vault 0.33 is the stable local transcription baseline. It promotes the accepted Alpha 8 Buildfix 3 implementation without adding the dedicated server/client runtime planned for the next development phase.

## Included

- Full-broadcast and five-minute local transcription.
- Multi-speaker diarisation and local remembered-voice review.
- Safe replacement of completed transcripts.
- Pause, resume, cancellation, retry and durable batch transcription.
- Transcript correction, phrase splitting and merging, speaker confirmation and TXT/SRT/VTT exports.
- Transcript-aware Search and transcript access from broadcast information and Now Playing.
- Complete transcript content, timings and speaker labels in Deep Research Packs.
- Long-form continuity, timestamp-mapping, repeated-output and implausible-speaker safeguards.
- The redesigned Transcript review, Transcription activity and Batch runs interface.

## Compatibility

- Database schema remains 45.
- Existing Library, playback, Research, transcript and Radio Vault Anywhere data remain in place.
- Radio Vault 0.33 continues to run as the accepted integrated local desktop application.
- The future RadioVault Server extraction must preserve this release as the recoverable migration baseline.
