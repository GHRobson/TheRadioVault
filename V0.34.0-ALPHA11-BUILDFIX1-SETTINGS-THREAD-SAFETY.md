# Radio Vault v0.34.0 Alpha 11 Buildfix 1 — Settings thread safety

This buildfix repairs the client crash recorded at 14:11 on 2 August 2026. The dedicated server responded successfully, but its Anywhere status notification was delivered from a worker thread. Settings then refreshed Avalonia button command state from that thread and Avalonia terminated the process with a thread-ownership exception.

Both Settings event boundaries now marshal state and command updates through the application UI dispatcher:

- Radio Vault Anywhere server status;
- paired-server Test, Reconnect and connection-state status.

## Acceptance

1. Start the matched Buildfix 1 server and client.
2. Open Settings repeatedly and move between every Settings section.
3. On Server connection, use Test and Reconnect.
4. On Radio Vault Anywhere, use Refresh/diagnostics where available.
5. Confirm the client remains open and buttons/status labels update normally.

All Alpha 11 server-client, playback, handoff and encrypted-cache behaviour is preserved.
