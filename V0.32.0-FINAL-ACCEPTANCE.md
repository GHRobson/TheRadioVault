# Radio Vault 0.32.0 final acceptance

The stable release is the user-accepted RC1 implementation with version and release documentation changes only.

## Accepted behavior

- The Avalonia desktop opens the existing Library and performs normal playback, seeking and resume behavior.
- Short recordings are not incorrectly completed by the five-minute final window.
- Approve, Keep existing, Ignore, Reopen and undo date-review workflows operate correctly.
- Research Pack export and import preserve resolved date-review decisions.
- Radio Vault Anywhere continues to operate as the browser and phone companion.
- The retired WPF shell and WPF/Windows adapter project are absent.

## Automated release gate

`RUN-RELEASE-GATE.cmd` must pass Avalonia-only source validation, architecture validation, a deterministic full-solution Release build, all 190 smoke tests and compiled product-version verification.
