# Radio Vault 0.34.0 Alpha 19 Buildfix 7

The Buildfix 6 diagnostic proves that the new server-positioned stream worked: its duration was exactly the original duration minus the requested 5.308-second resume point. Radio Vault Web nevertheless rejected it because the corresponding logical offset was attached later, during asynchronous manifest processing, and could be absent when alignment ran.

Buildfix 7 gives every audio source a canonical base position at the instant the source is assigned. A positioned iPhone stream receives the requested canonical position synchronously inside the playback gesture; a normal canonical part receives that part's logical start. The current shared playhead is therefore always the source base plus the decoder's local clock, with no later attachment window.

Install the Buildfix 7 server, fully close Radio Vault Web on the phone, reopen it and confirm Buildfix 7. Test the same broadcast that resumed at 5.308 seconds, an unplayed broadcast, and a handoff from the native client.
